## 1. 阶段目标

实现一期三张基础报表的后端接口，覆盖 PRD §4.6（RPT-01~RPT-03）：

- **RPT-01 需求明细表**：按需求来源、产品等维度查询需求明细
- **RPT-02 需求统计表**：按来源/状态/时间维度统计申请单数量
- **RPT-03 开发任务明细与统计表**：任务明细、完成率、排期达成
- **Excel 导出**：复用 pig-common-excel

> 考核指标看板（RPT-04）和进度看板（RPT-05）为二期/三期，不在本阶段范围。

## 3. RPT-01 需求明细表

### 3.1 需求

按需求来源、产品（关联客户/项目）、状态、时间区间查询需求明细，支持分页和 Excel 导出。

### 3.2 接口

```
GET /rm/report/requirement-detail
```

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| source | String | 需求来源（可选） |
| customerProject | String | 关联客户/项目（模糊，可选） |
| status | String | 需求状态（可选） |
| startDate | LocalDate | 创建时间起（可选） |
| endDate | LocalDate | 创建时间止（可选） |
| export | Boolean | 是否导出 Excel（默认 false） |

### 3.3 VO

```java
@Data
@Schema(description = "需求明细报表VO")
public class RequirementDetailReportVO {
    @ExcelProperty("申请单编号")
    private String reqCode;

    @ExcelProperty("需求标题")
    private String title;

    @ExcelProperty("需求来源")
    private String sourceDesc;      // 字典翻译后的中文

    @ExcelProperty("关联客户/项目")
    private String customerProject;

    @ExcelProperty("期望完成时间")
    private LocalDate expectCompleteDate;

    @ExcelProperty("发起人")
    private String initiatorName;

    @ExcelProperty("发起部门")
    private String initiatorDeptName;

    @ExcelProperty("当前状态")
    private String statusDesc;      // 字典翻译后的中文

    @ExcelProperty("设计工作量(人日)")
    private BigDecimal designWorkload;

    @ExcelProperty("计划设计完成")
    private LocalDate designPlanDate;

    @ExcelProperty("实际设计完成")
    private LocalDate designActualDate;

    @ExcelProperty("创建时间")
    private LocalDateTime createTime;
}
```

### 3.4 查询 SQL

```sql
SELECT
    r.req_code,
    r.title,
    r.source,
    r.customer_project,
    r.expect_complete_date,
    r.initiator_id,
    r.initiator_dept_id,
    r.status,
    r.design_workload,
    r.design_plan_date,
    r.design_actual_date,
    r.create_time
FROM rm_requirement r
WHERE r.del_flag = '0'
    AND (#{source} IS NULL OR r.source = #{source})
    AND (#{customerProject} IS NULL OR r.customer_project LIKE '%' || #{customerProject} || '%')
    AND (#{status} IS NULL OR r.status = #{status})
    AND (#{startDate} IS NULL OR r.create_time >= #{startDate})
    AND (#{endDate} IS NULL OR r.create_time <= #{endDate})
ORDER BY r.create_time DESC
```

> 发起人姓名、部门名称通过 JOIN `sys_user` / `sys_dept` 获取，或通过 MyBatis-Plus Join 查询。

### 4.4 统计 SQL

**按来源统计**（考核点 1）：

```sql
SELECT r.source AS key, COUNT(*) AS count
FROM rm_requirement r
WHERE r.del_flag = '0'
    AND (#{startDate} IS NULL OR r.create_time >= #{startDate})
    AND (#{endDate} IS NULL OR r.create_time <= #{endDate})
GROUP BY r.source
ORDER BY count DESC
```

**按状态统计**：

```sql
SELECT r.status AS key, COUNT(*) AS count
FROM rm_requirement r
WHERE r.del_flag = '0'
GROUP BY r.status
ORDER BY count DESC
```

**按月统计**（趋势）：

```sql
SELECT TO_CHAR(r.create_time, 'YYYY-MM') AS key, COUNT(*) AS count
FROM rm_requirement r
WHERE r.del_flag = '0'
    AND (#{startDate} IS NULL OR r.create_time >= #{startDate})
    AND (#{endDate} IS NULL OR r.create_time <= #{endDate})
GROUP BY TO_CHAR(r.create_time, 'YYYY-MM')
ORDER BY key
```

**设计工作量合计**（考核点 2）：

```sql
SELECT COALESCE(SUM(r.design_workload), 0) AS total_workload
FROM rm_requirement r
WHERE r.del_flag = '0'
    AND (#{startDate} IS NULL OR r.create_time >= #{startDate})
    AND (#{endDate} IS NULL OR r.create_time <= #{endDate})
```

```java
        private String reqCode;
        @ExcelProperty("负责人")
        private String assigneeName;
        @ExcelProperty("计划完成")
        private LocalDate planEndDate;
        @ExcelProperty("实际完成")
        private LocalDate actualEndDate;
        @ExcelProperty("状态")
        private String statusDesc;
        @ExcelProperty("是否排期达成")
        private String onSchedule;  // 是/否
    }

```

### 5.4 统计 SQL

**完成率**：

```sql
SELECT
    COUNT(*) AS total,
    COUNT(CASE WHEN status = 'COMPLETED' THEN 1 END) AS completed,
    COUNT(CASE WHEN status = 'COMPLETED' AND actual_end_date <= plan_end_date THEN 1 END) AS on_schedule
FROM rm_dev_task
WHERE del_flag = '0'
    AND (#{requirementId} IS NULL OR requirement_id = #{requirementId})
    AND (#{assigneeId} IS NULL OR assignee_id = #{assigneeId})
    AND (#{startDate} IS NULL OR create_time >= #{startDate})
    AND (#{endDate} IS NULL OR create_time <= #{endDate})
```

**按状态分布**：

```sql
SELECT status AS key, COUNT(*) AS count
FROM rm_dev_task
WHERE del_flag = '0'
    AND (#{requirementId} IS NULL OR requirement_id = #{requirementId})
GROUP BY status
```

### 6.2 `ReportServiceImpl.java`

```java
@Service
@AllArgsConstructor
public class ReportServiceImpl implements ReportService {

    private final ReportMapper reportMapper;

    @Override
    public IPage<RequirementDetailReportVO> requirementDetail(Page page, String source,
            String customerProject, String status, LocalDate startDate, LocalDate endDate) {
        return reportMapper.selectRequirementDetail(page, source, customerProject,
                status, startDate, endDate);
    }

    @Override
    public RequirementStatReportVO requirementStat(LocalDate startDate, LocalDate endDate) {
        RequirementStatReportVO vo = new RequirementStatReportVO();
        vo.setBySource(reportMapper.statBySource(startDate, endDate));
        vo.setByStatus(reportMapper.statByStatus());
        vo.setByMonth(reportMapper.statByMonth(startDate, endDate));
        vo.setTotal(reportMapper.countTotal(startDate, endDate));
        vo.setTotalDesignWorkload(reportMapper.sumDesignWorkload(startDate, endDate));
        return vo;
    }

    @Override
    public DevTaskStatReportVO devTaskStat(Long requirementId, Long assigneeId,
            LocalDate startDate, LocalDate endDate) {
        DevTaskStatReportVO vo = new DevTaskStatReportVO();

        // 统计数据
        Map<String, Object> stat = reportMapper.devTaskStatCount(requirementId, assigneeId,
                startDate, endDate);
        Long total = (Long) stat.get("total");
        Long completed = (Long) stat.get("completed");
        Long onSchedule = (Long) stat.get("on_schedule");
        vo.setTotalTasks(total);
        vo.setCompletedTasks(completed);
        vo.setOnScheduleTasks(onSchedule);
        vo.setCompletionRate(calcRate(completed, total));
        vo.setScheduleAchievementRate(calcRate(onSchedule, total));
        vo.setByStatus(reportMapper.devTaskStatByStatus(requirementId));
        vo.setDetails(reportMapper.devTaskDetailList(requirementId, assigneeId,
                startDate, endDate));
        return vo;
    }

    @Override
    public void export(String reportType, HttpServletResponse response,
            String source, String customerProject, String status,
            LocalDate startDate, LocalDate endDate,
            Long requirementId, Long assigneeId) throws Exception {

        response.setContentType("application/vnd.openxmlformats-officedocument.spreadsheetml.sheet");
        response.setCharacterEncoding("utf-8");

        switch (reportType) {
            case "requirement-detail" -> {
                String fileName = URLEncoder.encode("需求明细表", "UTF-8");
                response.setHeader("Content-disposition",
                        "attachment;filename*=utf-8''" + fileName + ".xlsx");
                // 使用 pig-common-excel 的 EasyExcel 导出
                List<RequirementDetailReportVO> data = reportMapper
                        .selectRequirementDetailList(source, customerProject, status,
                                startDate, endDate);
                com.alibaba.excel.EasyExcel.write(response.getOutputStream())
                        .head(RequirementDetailReportVO.class)
                        .sheet("需求明细")
                        .doWrite(data);
            }
            case "requirement-stat" -> {
                // 统计表导出（按来源/状态/月分别 sheet）
                // 省略具体实现
            }
            case "dev-task-stat" -> {
                // 开发任务统计导出
                // 省略
            }
        }
    }

    private BigDecimal calcRate(Long numerator, Long denominator) {
        if (denominator == null || denominator == 0) return BigDecimal.ZERO;
        return BigDecimal.valueOf(numerator)
                .multiply(BigDecimal.valueOf(100))
                .divide(BigDecimal.valueOf(denominator), 2, RoundingMode.HALF_UP);
    }
}
```

## 7. Mapper 层

### 7.1 `ReportMapper.java`

```java
@Mapper
public interface ReportMapper extends BaseMapper<Object> {

    // ========== RPT-01 需求明细 ==========

    @Select("""
        <script>
        SELECT r.req_code, r.title, r.source, r.customer_project,
               r.expect_complete_date, r.initiator_id, r.initiator_dept_id,
               r.status, r.design_workload, r.design_plan_date, r.design_actual_date,
               r.create_time
        FROM rm_requirement r
        WHERE r.del_flag = '0'
            <if test="source != null and source != ''">AND r.source = #{source}</if>
            <if test="customerProject != null and customerProject != ''">
                AND r.customer_project LIKE CONCAT('%', #{customerProject}, '%')
            </if>
            <if test="status != null and status != ''">AND r.status = #{status}</if>
            <if test="startDate != null">AND r.create_time >= #{startDate}</if>
            <if test="endDate != null">AND r.create_time &lt;= #{endDate}</if>
        ORDER BY r.create_time DESC
        </script>
        """)
    IPage<RequirementDetailReportVO> selectRequirementDetail(
            Page page,
            @Param("source") String source,
            @Param("customerProject") String customerProject,
            @Param("status") String status,
            @Param("startDate") LocalDate startDate,
            @Param("endDate") LocalDate endDate);

    // ========== RPT-02 需求统计 ==========

    @Select("""
        SELECT r.source AS key, COUNT(*) AS count
        FROM rm_requirement r
        WHERE r.del_flag = '0'
            AND (#{startDate} IS NULL OR r.create_time >= #{startDate})
            AND (#{endDate} IS NULL OR r.create_time <= #{endDate})
        GROUP BY r.source ORDER BY count DESC
        """)
    List<RequirementStatReportVO.StatItem> statBySource(
            @Param("startDate") LocalDate startDate,
            @Param("endDate") LocalDate endDate);

    @Select("""
        SELECT r.status AS key, COUNT(*) AS count
        FROM rm_requirement r
        WHERE r.del_flag = '0'
        GROUP BY r.status ORDER BY count DESC
        """)
    List<RequirementStatReportVO.StatItem> statByStatus();

    @Select("""
        SELECT TO_CHAR(r.create_time, 'YYYY-MM') AS key, COUNT(*) AS count
        FROM rm_requirement r
        WHERE r.del_flag = '0'
            AND (#{startDate} IS NULL OR r.create_time >= #{startDate})
            AND (#{endDate} IS NULL OR r.create_time <= #{endDate})
        GROUP BY TO_CHAR(r.create_time, 'YYYY-MM')
        ORDER BY key
        """)
    List<RequirementStatReportVO.StatItem> statByMonth(
            @Param("startDate") LocalDate startDate,
            @Param("endDate") LocalDate endDate);

    @Select("""
        SELECT COUNT(*) FROM rm_requirement
        WHERE del_flag = '0'
            AND (#{startDate} IS NULL OR create_time >= #{startDate})
            AND (#{endDate} IS NULL OR create_time <= #{endDate})
        """)
    Long countTotal(@Param("startDate") LocalDate startDate,
                    @Param("endDate") LocalDate endDate);

    @Select("""
        SELECT COALESCE(SUM(design_workload), 0)
        FROM rm_requirement
        WHERE del_flag = '0'
            AND (#{startDate} IS NULL OR create_time >= #{startDate})
            AND (#{endDate} IS NULL OR create_time <= #{endDate})
        """)
    BigDecimal sumDesignWorkload(@Param("startDate") LocalDate startDate,
                                 @Param("endDate") LocalDate endDate);

    // ========== RPT-03 开发任务统计 ==========

    @Select("""
        SELECT
            COUNT(*) AS total,
            COUNT(CASE WHEN status = 'COMPLETED' THEN 1 END) AS completed,
            COUNT(CASE WHEN status = 'COMPLETED' AND actual_end_date <= plan_end_date
                  THEN 1 END) AS on_schedule
        FROM rm_dev_task
        WHERE del_flag = '0'
            AND (#{requirementId} IS NULL OR requirement_id = #{requirementId})
            AND (#{assigneeId} IS NULL OR assignee_id = #{assigneeId})
            AND (#{startDate} IS NULL OR create_time >= #{startDate})
            AND (#{endDate} IS NULL OR create_time <= #{endDate})
        """)
    Map<String, Object> devTaskStatCount(
            @Param("requirementId") Long requirementId,
            @Param("assigneeId") Long assigneeId,
            @Param("startDate") LocalDate startDate,
            @Param("endDate") LocalDate endDate);

    @Select("""
        SELECT status AS key, COUNT(*) AS count
        FROM rm_dev_task
        WHERE del_flag = '0'
            AND (#{requirementId} IS NULL OR requirement_id = #{requirementId})
        GROUP BY status
        """)
    List<DevTaskStatReportVO.StatItem> devTaskStatByStatus(
            @Param("requirementId") Long requirementId);
}
```

> `ReportMapper` 继承 `BaseMapper<Object>`（不绑定具体实体），仅用于注解 SQL 查询。不使用 `MPJBaseMapper`，因为报表查询不涉及 MyBatis-Plus 的 CRUD 能力。

## 9. 考核指标数据来源映射

本阶段落地的三张报表覆盖以下考核点（部分）：

| 考核点 | 数据来源 | 报表 | 统计方式 |
| --- | --- | --- | --- |
| 1. 申请单数量 | `rm_requirement` | RPT-02 | 按来源/月 COUNT |
| 2. 需求设计工作量 | `rm_requirement.design_workload` | RPT-02 | SUM(design_workload) |
| 3. 需求设计按时完成 | `design_plan_date` vs `design_actual_date` | RPT-01 | 明细展示，可扩展统计 |

## 10. 字典翻译策略

报表中的来源、状态等枚举值需要翻译为中文展示。两种策略：

| 策略 | 实现 | 适用 |
| --- | --- | --- |
| 后端翻译 | Service 层查询后遍历，用 `sys_dict_item` 翻译 | 列表数据量适中 |
| 前端翻译 | 前端用字典组件（`<dict-tag>`）渲染 | 列表展示 |

一期采用**前端翻译**（沿用 pig-ui 的 `dict-util` 能力），后端仅返回枚举值（`source`/`status`），导出 Excel 时在后端翻译。

## 11. 性能优化

| 场景 | 优化措施 |
| --- | --- |
| 报表查询慢 | PostgreSQL 已有索引 `idx_rm_req_status`/`idx_rm_req_source`/`idx_rm_dev_status` |
| 统计 SQL | 使用 `COUNT(CASE WHEN ...)` 单次查询聚合，减少数据库往返 |
| 导出大数据量 | EasyExcel 流式写入，不分页全量查询（数据量 <10w 可接受） |
| 缓存 | 二期考核看板引入 Redis 缓存（TTL 5min），一期不缓存 |
