## 1. 阶段目标

实现软件需求申请单（`rm_requirement`）的完整后端业务逻辑，覆盖 PRD §3.2 需求管理流程与 §4.2 全部功能项（REQ-01~REQ-10）：

- 四类来源需求创建与提交，自动生成编号（REQ-01/02）
- 多级审批链路：交付中心审批 → 产品经理审批 → 讨论会评审（REQ-03/04）
- 需求分析设计（富文本+附件）（REQ-05）
- 需求设计评审，通过/驳回（REQ-06）
- 开发排期，产品经理跟进时间风险（REQ-07）
- 排期计划查看（REQ-08）
- 测试通过+质量确认后状态自动完成（REQ-09）
- 发起人验收（REQ-10）
- 状态机引擎 + 审批流程引擎 + 编号生成器

### 4.3 状态机 `RequirementStateMachine.java`

```java
package com.pig4cloud.pig.rm.statemachine;

import com.pig4cloud.pig.common.core.exception.CheckedException;
import org.springframework.stereotype.Component;

import java.util.Map;

import static com.pig4cloud.pig.rm.statemachine.RequirementEventEnum.*;
import static com.pig4cloud.pig.rm.statemachine.RequirementStatusEnum.*;

/**
 * 需求状态机（默认转移表）
 * 转移规则可被 rm_flow_node 配置覆盖（见 FlowEngine）
 */
@Component
public class RequirementStateMachine {

    /**
     * 转移表 key = (当前状态, 事件)
     */
    private record StatusEvent(RequirementStatusEnum status, RequirementEventEnum event) {}

    private static final Map<StatusEvent, RequirementStatusEnum> TRANSITIONS = Map.ofEntries(
            Map.entry(new StatusEvent(DRAFT, SUBMIT), PENDING_APPROVAL),
            Map.entry(new StatusEvent(PENDING_APPROVAL, APPROVE_PASS), PENDING_REVIEW),
            Map.entry(new StatusEvent(PENDING_APPROVAL, APPROVE_REJECT), REJECTED),
            Map.entry(new StatusEvent(REJECTED, RESUBMIT), PENDING_APPROVAL),
            Map.entry(new StatusEvent(PENDING_REVIEW, REVIEW_PASS), DESIGNING),
            Map.entry(new StatusEvent(PENDING_REVIEW, REVIEW_FAIL), REJECTED),
            Map.entry(new StatusEvent(DESIGNING, DESIGN_SUBMIT), DESIGN_REVIEW),
            Map.entry(new StatusEvent(DESIGN_REVIEW, DESIGN_REVIEW_PASS), SCHEDULING),
            Map.entry(new StatusEvent(DESIGN_REVIEW, DESIGN_REVIEW_FAIL), DESIGNING),
            Map.entry(new StatusEvent(SCHEDULING, SCHEDULE_CONFIRM), DEVELOPING),
            Map.entry(new StatusEvent(DEVELOPING, DEV_COMPLETE), TESTING),
            Map.entry(new StatusEvent(TESTING, TEST_REJECT), DEVELOPING),
            Map.entry(new StatusEvent(TESTING, TEST_PASS), PENDING_ACCEPTANCE),
            Map.entry(new StatusEvent(PENDING_ACCEPTANCE, ACCEPT), COMPLETED),
            Map.entry(new StatusEvent(COMPLETED, RELEASE), RELEASED)
    );

    /**
     * 执行状态转移
     *
     * @param current 当前状态
     * @param event   触发事件
     * @return 目标状态
     */
    public RequirementStatusEnum transit(RequirementStatusEnum current, RequirementEventEnum event) {
        RequirementStatusEnum next = TRANSITIONS.get(new StatusEvent(current, event));
        if (next == null) {
            throw new CheckedException(
                    "非法状态转移: " + current.getDescription() + " + " + event.getDescription());
        }
        return next;
    }

    /**
     * 检查转移是否合法（不抛异常）
     */
    public boolean canTransit(RequirementStatusEnum current, RequirementEventEnum event) {
        return TRANSITIONS.containsKey(new StatusEvent(current, event));
    }
}
```

> **审批通过后是否走讨论会**：`APPROVE_PASS` 默认转入 `PENDING_REVIEW`（待评审）。若 `need_review='0'`（不需讨论会），`FlowEngine` 在执行审批通过时直接跳转到 `DESIGNING`，覆盖默认转移。此逻辑在 `ApprovalService.approve()` 中实现，而非状态机内部。

## 5. 编号生成器 `CodeGeneratorService.java`

```java
package com.pig4cloud.pig.rm.service;

import lombok.AllArgsConstructor;
import org.springframework.data.redis.core.StringRedisTemplate;
import org.springframework.stereotype.Service;

import java.time.LocalDate;
import java.time.format.DateTimeFormatter;
import java.util.concurrent.TimeUnit;

/**
 * 统一编号生成器（基于 Redis 原子递增）
 * 规则：PREFIX-YYYYMMDD-XXX（XXX 为当日递增序号，3位补零）
 */
@Service
@AllArgsConstructor
public class CodeGeneratorService {

    private final StringRedisTemplate redisTemplate;

    /**
     * 生成编号
     *
     * @param prefix 前缀，如 REQ / DEV / TST / BUG
     * @return 编号字符串
     */
    public String next(String prefix) {
        String date = LocalDate.now().format(DateTimeFormatter.ofPattern("yyyyMMdd"));
        String key = "rm:seq:" + prefix + ":" + date;
        Long seq = redisTemplate.opsForValue().increment(key);
        // 首次创建时设置过期（2天后自动清理）
        redisTemplate.expire(key, 2, TimeUnit.DAYS);
        return prefix + "-" + date + "-" + String.format("%03d", seq);
    }
}
```

**编号规则汇总**：

| 单据 | 前缀 | 示例 |
| --- | --- | --- |
| 需求申请单 | REQ | REQ-20260729-001 |
| 开发任务单 | DEV | DEV-20260729-001 |
| 测试任务单 | TST | TST-20260729-001 |
| Bug | BUG | BUG-20260729-001 |
| 测试用例 | CASE | CASE-20260729-001 |

## 6. 审批流程引擎 `FlowEngine.java`

```java
package com.pig4cloud.pig.rm.flow;

import com.pig4cloud.pig.rm.api.entity.FlowNode;
import com.pig4cloud.pig.rm.mapper.FlowNodeMapper;
import lombok.AllArgsConstructor;
import org.springframework.stereotype.Component;

import java.util.List;

/**
 * 审批流程引擎
 * 1. 查询 rm_flow_node 获取流程节点配置
 * 2. 根据 approver_type 解析审批人
 * 3. 返回当前节点配置供 Service 层驱动状态流转
 */
@Component
@AllArgsConstructor
public class FlowEngine {

    private final FlowNodeMapper flowNodeMapper;

    /**
     * 获取流程的全部节点（按顺序）
     */
    public List<FlowNode> getFlowNodes(String flowCode) {
        return flowNodeMapper.selectList(
                new com.baomidou.mybatisplus.core.toolkit.Wrappers<FlowNode>()
                        .lambdaQuery()
                        .eq(FlowNode::getFlowCode, flowCode)
                        .orderByAsc(FlowNode::getSortOrder));
    }

    /**
     * 获取指定节点配置
     */
    public FlowNode getNode(String flowCode, String nodeCode) {
        return flowNodeMapper.selectOne(
                new com.baomidou.mybatisplus.core.toolkit.Wrappers<FlowNode>()
                        .lambdaQuery()
                        .eq(FlowNode::getFlowCode, flowCode)
                        .eq(FlowNode::getNodeCode, nodeCode));
    }

    /**
     * 获取流程的起始节点
     * 对需求流程：交付中心需求(CUSTOMER_DELIVERY)从 DELIVERY_APPROVAL 开始，
     * 其他来源从 PRODUCT_APPROVAL 开始
     */
    public FlowNode getStartNode(String flowCode, String source) {
        String startNodeCode = "CUSTOMER_DELIVERY".equals(source)
                ? "DELIVERY_APPROVAL"
                : "PRODUCT_APPROVAL";
        return getNode(flowCode, startNodeCode);
    }
}
```

> 审批人解析逻辑（`ROLE`/`DEPT_LEADER`/`USER`/`INITIATOR_LEADER`）通过 pig 的 `SysUser` Feign 或直接查 `sys_user`/`sys_role`/`sys_user_role`/`sys_dept` 表实现。本阶段在 `RequirementService` 中直接注入 `SysUserMapper`（单体模式）或通过 Feign（微服务模式）获取用户列表。

### 7.2 `RequirementServiceImpl.java`（核心方法实现）

```java
package com.pig4cloud.pig.rm.service.impl;

import com.pig4cloud.pig.common.core.util.R;
import com.pig4cloud.pig.common.core.exception.CheckedException;
import com.pig4cloud.pig.common.security.util.SecurityUtils;
import com.pig4cloud.pig.rm.api.entity.*;
import com.pig4cloud.pig.rm.api.dto.*;
import com.pig4cloud.pig.rm.mapper.*;
import com.pig4cloud.pig.rm.service.*;
import com.pig4cloud.pig.rm.statemachine.*;
import com.pig4cloud.pig.rm.flow.FlowEngine;
import lombok.AllArgsConstructor;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.time.LocalDateTime;

@Service
@AllArgsConstructor
public class RequirementServiceImpl
        extends com.baomidou.mybatisplus.extension.service.impl.ServiceImpl<RequirementMapper, Requirement>
        implements RequirementService {

    private final CodeGeneratorService codeGenerator;
    private final RequirementStateMachine stateMachine;
    private final FlowEngine flowEngine;
    private final ApprovalRecordMapper approvalRecordMapper;
    private final TodoService todoService;
    private final NotifyService notifyService;

    @Override
    @Transactional(rollbackFor = Exception.class)
    public R saveRequirement(Requirement req) {
        // 1. 自动赋值
        req.setReqCode(codeGenerator.next("REQ"));
        req.setStatus(RequirementStatusEnum.DRAFT.name());
        req.setInitiatorId(SecurityUtils.getUser().getId());
        req.setInitiatorDeptId(SecurityUtils.getUser().getDeptId());
        req.setNeedReview(req.getNeedReview() != null ? req.getNeedReview() : "0");
        req.setPriority(req.getPriority() != null ? req.getPriority() : "MEDIUM");
        // 2. 保存
        save(req);
        return R.ok(req);
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public R submit(Long id) {
        Requirement req = getById(id);
        if (req == null) return R.failed("需求不存在");

        // 1. 状态流转：DRAFT → PENDING_APPROVAL
        RequirementStatusEnum next = stateMachine.transit(
                RequirementStatusEnum.valueOf(req.getStatus()),
                RequirementEventEnum.SUBMIT);
        req.setStatus(next.name());

        // 2. 更新需求
        updateById(req);

        // 3. 启动审批流：根据来源确定起始节点
        FlowNode startNode = flowEngine.getStartNode("REQUIREMENT_FLOW", req.getSource());

        // 4. 生成审批待办 + 通知
        todoService.createTodoForNode(startNode, "REQUIREMENT", id,
                "待审批：" + req.getReqCode() + " " + req.getTitle());
        notifyService.notifyApprovers(startNode, "REQUIREMENT", id,
                req.getReqCode(), req.getTitle());

        return R.ok("提交成功");
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public R approve(RequirementApproveDTO dto) {
        Requirement req = getById(dto.getBillId());
        if (req == null) return R.failed("需求不存在");
        if (!RequirementStatusEnum.PENDING_APPROVAL.name().equals(req.getStatus())) {
            return R.failed("当前状态不可审批");
        }

        // 1. 记录审批记录（只增不删）
        ApprovalRecord record = new ApprovalRecord();
        record.setBillType("REQUIREMENT");
        record.setBillId(req.getId());
        record.setNodeCode(dto.getNodeCode());
        record.setApproverId(SecurityUtils.getUser().getId());
        record.setConclusion(dto.getConclusion());
        record.setOpinion(dto.getOpinion());
        record.setApproveTime(LocalDateTime.now());
        approvalRecordMapper.insert(record);

        // 2. 关闭当前节点的审批待办
        todoService.closeTodo("REQUIREMENT", req.getId(), dto.getNodeCode());

        RequirementStatusEnum currentStatus = RequirementStatusEnum.valueOf(req.getStatus());

        if ("PASS".equals(dto.getConclusion())) {
            // 3a. 审批通过
            RequirementEventEnum event = RequirementEventEnum.APPROVE_PASS;
            RequirementStatusEnum next = stateMachine.transit(currentStatus, event);

            // 判断是否需要讨论会评审
            if ("1".equals(req.getNeedReview())) {
                // 需要讨论会 → PENDING_REVIEW
                req.setStatus(RequirementStatusEnum.PENDING_REVIEW.name());
            } else {
                // 不需要讨论会 → 直接进入设计
                req.setStatus(RequirementStatusEnum.DESIGNING.name());
                // 生成设计待办给产品经理
                FlowNode designNode = flowEngine.getNode("REQUIREMENT_FLOW", "DESIGN");
                todoService.createTodoForNode(designNode, "REQUIREMENT", req.getId(),
                        "待设计：" + req.getReqCode());
                notifyService.notifyApprovers(designNode, "REQUIREMENT", req.getId(),
                        req.getReqCode(), req.getTitle());
            }
            updateById(req);
        } else {
            // 3b. 审批驳回（必填原因）
            if (dto.getOpinion() == null || dto.getOpinion().isBlank()) {
                return R.failed("驳回必须填写原因");
            }
            RequirementStatusEnum next = stateMachine.transit(currentStatus,
                    RequirementEventEnum.APPROVE_REJECT);
            req.setStatus(next.name());
            updateById(req);
            // 通知发起人被驳回
            notifyService.notifyUser(req.getInitiatorId(), "REJECT",
                    "需求被驳回：" + req.getReqCode(), dto.getOpinion());
        }

        return R.ok("审批完成");
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public R saveDesign(RequirementDesignDTO dto) {
        Requirement req = getById(dto.getRequirementId());
        if (req == null) return R.failed("需求不存在");
        if (!RequirementStatusEnum.DESIGNING.name().equals(req.getStatus())) {
            return R.failed("当前状态不可保存设计");
        }
        req.setDesignContent(dto.getDesignContent());
        req.setDesignWorkload(dto.getDesignWorkload());
        req.setDesignPlanDate(dto.getDesignPlanDate());
        updateById(req);
        return R.ok("设计已保存");
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public R submitDesignReview(Long id) {
        Requirement req = getById(id);
        RequirementStatusEnum next = stateMachine.transit(
                RequirementStatusEnum.valueOf(req.getStatus()),
                RequirementEventEnum.DESIGN_SUBMIT);
        // 记录实际设计完成时间（考核点3）
        req.setDesignActualDate(java.time.LocalDate.now());
        req.setStatus(next.name());
        updateById(req);

        // 生成设计评审待办给领导
        FlowNode reviewNode = flowEngine.getNode("REQUIREMENT_FLOW", "DESIGN_REVIEW");
        todoService.createTodoForNode(reviewNode, "REQUIREMENT", id,
                "待设计评审：" + req.getReqCode());
        notifyService.notifyApprovers(reviewNode, "REQUIREMENT", id,
                req.getReqCode(), req.getTitle());
        return R.ok("已提交设计评审");
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public R designReview(RequirementApproveDTO dto) {
        Requirement req = getById(dto.getBillId());
        RequirementStatusEnum current = RequirementStatusEnum.valueOf(req.getStatus());

        // 记录审批记录
        ApprovalRecord record = buildRecord(req.getId(), dto, "DESIGN_REVIEW");
        approvalRecordMapper.insert(record);
        todoService.closeTodo("REQUIREMENT", req.getId(), "DESIGN_REVIEW");

        RequirementEventEnum event = "PASS".equals(dto.getConclusion())
                ? RequirementEventEnum.DESIGN_REVIEW_PASS
                : RequirementEventEnum.DESIGN_REVIEW_FAIL;
        RequirementStatusEnum next = stateMachine.transit(current, event);
        req.setStatus(next.name());
        updateById(req);

        if (next == RequirementStatusEnum.SCHEDULING) {
            // 评审通过 → 生成排期待办给开发经理
            FlowNode scheduleNode = flowEngine.getNode("REQUIREMENT_FLOW", "SCHEDULE");
            todoService.createTodoForNode(scheduleNode, "REQUIREMENT", req.getId(),
                    "待排期：" + req.getReqCode());
        } else if (next == RequirementStatusEnum.DESIGNING) {
            // 评审不通过 → 退回重新设计，通知产品经理
            notifyService.notifyUser(req.getInitiatorId(), "REJECT",
                    "设计评审未通过：" + req.getReqCode(), dto.getOpinion());
        }
        return R.ok("评审完成");
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public R schedule(RequirementScheduleDTO dto) {
        Requirement req = getById(dto.getRequirementId());
        RequirementStatusEnum next = stateMachine.transit(
                RequirementStatusEnum.valueOf(req.getStatus()),
                RequirementEventEnum.SCHEDULE_CONFIRM);
        req.setScheduleRemark(dto.getScheduleRemark());
        req.setScheduleRisk(dto.getScheduleRisk() != null ? dto.getScheduleRisk() : "NORMAL");
        req.setStatus(next.name());  // DEVELOPING
        updateById(req);

        // 通知发起人排期已完成（PRD：发起人查看排期计划）
        notifyService.notifyUser(req.getInitiatorId(), "APPROVAL",
                "需求已排期：" + req.getReqCode(), req.getScheduleRemark());
        return R.ok("排期完成");
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public R qualityConfirm(Long id) {
        Requirement req = getById(id);
        if (!RequirementStatusEnum.TESTING.name().equals(req.getStatus())) {
            return R.failed("当前状态不可进行质量确认");
        }
        // 质量确认 + 测试通过 → 自动流转到待验收
        // 注意：此方法与 TestTaskService.pass() 配合使用
        // 当测试通过后，产品经理调用此方法确认质量，系统自动完成
        RequirementStatusEnum next = stateMachine.transit(
                RequirementStatusEnum.TESTING,
                RequirementEventEnum.TEST_PASS);
        req.setStatus(next.name());  // PENDING_ACCEPTANCE
        req.setCompleteTime(LocalDateTime.now());
        updateById(req);

        // 通知发起人验收
        notifyService.notifyUser(req.getInitiatorId(), "APPROVAL",
                "需求已完成，待验收：" + req.getReqCode(), "请及时验收");
        return R.ok("质量确认完成，需求状态已更新为待验收");
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public R accept(Long id, String conclusion, String remark) {
        Requirement req = getById(id);
        RequirementStatusEnum next = stateMachine.transit(
                RequirementStatusEnum.valueOf(req.getStatus()),
                RequirementEventEnum.ACCEPT);
        req.setStatus(next.name());  // COMPLETED
        req.setAcceptConclusion(conclusion);
        req.setAcceptRemark(remark);
        updateById(req);
        return R.ok("验收完成");
    }

    @Override
    public IPage<Requirement> page(Page page, RequirementQueryDTO query) {
        return baseMapper.selectPage(page,
                new com.baomidou.mybatisplus.core.toolkit.Wrappers<Requirement>()
                        .lambdaQuery()
                        .eq(query.getSource() != null, Requirement::getSource, query.getSource())
                        .eq(query.getStatus() != null, Requirement::getStatus, query.getStatus())
                        .eq(query.getInitiatorId() != null, Requirement::getInitiatorId, query.getInitiatorId())
                        .ge(query.getStartDate() != null, Requirement::getCreateTime, query.getStartDate())
                        .le(query.getEndDate() != null, Requirement::getCreateTime, query.getEndDate())
                        .like(query.getKeyword() != null, Requirement::getTitle, query.getKeyword())
                        .orderByDesc(Requirement::getCreateTime));
    }

    // 私有方法：构建审批记录
    private ApprovalRecord buildRecord(Long billId, RequirementApproveDTO dto, String nodeCode) {
        ApprovalRecord record = new ApprovalRecord();
        record.setBillType("REQUIREMENT");
        record.setBillId(billId);
        record.setNodeCode(nodeCode);
        record.setApproverId(SecurityUtils.getUser().getId());
        record.setConclusion(dto.getConclusion());
        record.setOpinion(dto.getOpinion());
        record.setApproveTime(LocalDateTime.now());
        return record;
    }
}
```

## 12. 关键业务规则校验

| 规则 | 实现位置 | 说明 |
| --- | --- | --- |
| 仅草稿/已驳回可编辑 | `updateRequirement()` | 校验 status IN (DRAFT, REJECTED) |
| 仅草稿可删除 | `removeRequirement()` | 校验 status = DRAFT |
| 驳回必填原因 | `approve()` | conclusion=REJECT 时 opinion 非空 |
| 非法状态转移 | `stateMachine.transit()` | 抛 CheckedException |
| 编号唯一 | DB 唯一约束 `uk_rm_req_code` + Redis 原子递增 | 双重保障 |
| 审批人校验 | `approve()` | 校验当前用户是否为该节点审批人 |
| need_review 影响 | `approve()` | 审批通过时根据 need_review 决定流转目标 |

## 13. 验收标准

| 序号 | 验收项 | 验证方法 |
| --- | --- | --- |
| AC-1.3.1 | 创建需求自动生成编号 | POST /rm/requirement 返回 req_code 格式为 REQ-YYYYMMDD-XXX |
| AC-1.3.2 | 提交后状态变为待审批 | 提交后查询 status=PENDING_APPROVAL |
| AC-1.3.3 | 审批通过(需讨论会)流转待评审 | need_review=1 时审批通过 status=PENDING_REVIEW |
| AC-1.3.4 | 审批通过(不需讨论会)流转设计中 | need_review=0 时审批通过 status=DESIGNING |
| AC-1.3.5 | 驳回必填原因 | opinion 为空时返回 R.failed |
| AC-1.3.6 | 设计评审通过流转排期中 | designReview PASS 后 status=SCHEDULING |
| AC-1.3.7 | 设计评审不通过退回设计中 | designReview FAIL 后 status=DESIGNING |
| AC-1.3.8 | 排期确认流转开发中 | schedule 后 status=DEVELOPING |
| AC-1.3.9 | 质量确认流转待验收 | qualityConfirm 后 status=PENDING_ACCEPTANCE |
| AC-1.3.10 | 验收通过流转已完成 | accept 后 status=COMPLETED |
| AC-1.3.11 | 非法状态转移报错 | 在已完成状态提交审批返回错误 |
| AC-1.3.12 | 审批记录只增不删 | 审批记录无 update/delete 接口 |
| AC-1.3.13 | 表单配置查询 | GET /rm/form-config/REQUIREMENT 返回字段配置列表 |
