## 1. 阶段目标

实现一期 MVP 全部前端页面，覆盖需求管理、开发管理、测试管理、待办中心、基础报表五大模块的列表/表单/详情页，与后端接口（阶段 1.3~1.7）对接。

前端沿用 pig-ui 的 Vue3 + TypeScript + Element Plus 技术栈，路由由后端菜单驱动（`backEnd.ts` 通过 `import.meta.glob` 自动解析）。

import { useI18n } from 'vue-i18n';
import { useMessage, useTable } from '/@/hooks';
import { pageList } from '/@/api/rm/requirement';
import { useDict } from '/@/hooks/dict';

const { t } = useI18n();
const { message } = useMessage();
const { tableStyle } = useTable();

const sourceOptions = useDict('rm_req_source');
const statusOptions = useDict('rm_req_status');

const queryRef = ref();
const formRef = ref();
const showSearch = ref(true);

const state = reactive({
  queryForm: { source: '', status: '', keyword: '' },
  dataList: [] as any[],
  loading: false,
  pageNum: 1,
  pageSize: 10,
  total: 0,
});

// 状态色标映射
const statusTagType = (status: string) => {
  const map: Record<string, string> = {
    DRAFT: 'info', PENDING_APPROVAL: 'warning', REJECTED: 'danger',
    PENDING_REVIEW: 'warning', DESIGNING: '', DESIGN_REVIEW: 'warning',
    SCHEDULING: '', DEVELOPING: '', TESTING: '',
    PENDING_ACCEPTANCE: 'success', COMPLETED: 'success', RELEASED: '',
  };
  return map[status] || 'info';
};

const statusLabel = (status: string) => {
  return statusOptions.value.find((item: any) => item.value === status)?.label || status;
};

const getDataList = async () => {
  state.loading = true;
  try {
    const { data } = await pageList({
      ...state.queryForm,
      current: state.pageNum,
      size: state.pageSize,
    });
    state.dataList = data.records;
    state.total = data.total;
  } finally {
    state.loading = false;
  }
};

const resetQuery = () => {
  queryRef.value?.resetFields();
  state.pageNum = 1;
  getDataList();
};

const rowClick = (row: any) => goDetail(row.id);
const goDetail = (id: string) => {
  router.push({ path: '/admin/rm/requirement/detail', query: { id } });
};

onMounted(() => getDataList());
</script>

<script lang="ts" name="rmDevTaskForm" setup>
import { createTasks } from '/@/api/rm/dev-task';

const emit = defineEmits(['refresh']);
const visible = ref(false);
const state = reactive({
  requirementId: '' as string,
  tasks: [{ taskName: '', assigneeId: '', planStartDate: '', planEndDate: '' }],
});

const openDialog = (requirementId: string) => {
  state.requirementId = requirementId;
  state.tasks = [{ taskName: '', assigneeId: '', planStartDate: '', planEndDate: '' }];
  visible.value = true;
};

const addTask = () => {
  state.tasks.push({ taskName: '', assigneeId: '', planStartDate: '', planEndDate: '' });
};

const removeTask = (index: number) => {
  state.tasks.splice(index, 1);
};

const onSubmit = async () => {
  await createTasks(state.requirementId, state.tasks);
  useMessage().success('任务分解成功');
  visible.value = false;
  emit('refresh');
};

defineExpose({ openDialog });
</script>

## 6. 路由与菜单

前端路由由后端菜单驱动，本阶段无需修改 `web/src/router/` 下任何文件。

V20 菜单种子已配置 `component_path`，`backEnd.ts` 通过 `import.meta.glob('../views/**/*.{vue,tsx}')` 自动解析：

| 菜单 component_path | 解析到文件 |
| --- | --- |
| `admin/rm/requirement/index` | `web/src/views/admin/rm/requirement/index.vue` |
| `admin/rm/dev-task/index` | `web/src/views/admin/rm/dev-task/index.vue` |
| `admin/rm/test/case/index` | `web/src/views/admin/rm/test/case/index.vue` |
| `admin/rm/report/requirement-detail` | `web/src/views/admin/rm/report/requirement-detail.vue` |
| `admin/rm/todo/index` | `web/src/views/admin/rm/todo/index.vue` |

> 详情页（detail.vue）不在菜单中，通过列表页跳转 `router.push` 访问。需在路由配置中确保子路由可访问——pig-ui 的 `backEnd.ts` 会将菜单 `componentPath` 解析为路由 `component`，但非菜单页面需要通过 `router.addRoute` 动态添加或使用 `name` 导航。一期采用 `router.push({ path: '/admin/rm/requirement/detail', query: { id } })` 方式，在 `route.ts` 的 `baseRoutes` 中预设通配路由或使用 query 参数 + 动态组件加载。

**简化方案**：详情页改用弹窗（`el-dialog`）而非独立路由页面，避免路由配置复杂度。需求详情/任务详情/测试任务单详情均在列表页内以弹窗或 splitpanes 右侧面板展示。
