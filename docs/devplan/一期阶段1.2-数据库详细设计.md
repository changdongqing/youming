## 3. DDL 设计规范

沿用 `V4__ont_governance_schema.sql` 确立的 PostgreSQL 方言约定：

| 规范 | 说明 |
| --- | --- |
| 表名前缀 | `rm_` |
| 主键 | `id bigint NOT NULL`，雪花 ID（应用层赋值，不使用 bigserial） |
| 主键约束 | `CONSTRAINT pk_rm_<table> PRIMARY KEY (id)` |
| 唯一约束 | `CONSTRAINT uk_rm_<table>_<col> UNIQUE (...)` |
| 审计字段 | `create_by varchar(64) DEFAULT ' '`、`create_time timestamp DEFAULT now()`、`update_by varchar(64) DEFAULT ' '`、`update_time timestamp DEFAULT now()`、`del_flag char(1) DEFAULT '0'` |
| 布尔标记 | `char(1)`：`'0'`/`'1'` |
| 状态字段 | `varchar(32)`，存枚举名 |
| 注释 | `COMMENT ON TABLE` / `COMMENT ON COLUMN`，每列必加 |
| 租户 | `tenant_id bigint`（pig 多租户字段） |
| 索引 | `CREATE INDEX idx_rm_<table>_<col> ON rm_<table>(<col>)` |

### 4.1 `rm_requirement` — 软件需求申请单

```sql
-- ============================================================
-- 4.1 软件需求申请单
-- 对应 PRD 4.2.2 / 设计计划 §3.3.1
-- ============================================================
CREATE TABLE rm_requirement (
    id                      bigint       NOT NULL,
    req_code                varchar(32)  NOT NULL,
    title                   varchar(255) NOT NULL,
    source                  varchar(32)  NOT NULL,
    customer_project        varchar(255),
    description             text         NOT NULL,
    expect_complete_date    date         NOT NULL,
    initiator_id            bigint       NOT NULL,
    initiator_dept_id       bigint       NOT NULL,

    review_conclusion       varchar(32),
    review_remark           text,

    design_plan_date        date,
    design_actual_date      date,
    schedule_remark         text,
    schedule_risk           varchar(32),

    accept_remark           text,
```
