## 1. 阶段目标

实现开发任务单（`rm_dev_task`）的完整后端业务逻辑，覆盖 PRD §3.3 开发管理流程与 §4.3 全部功能项（DEV-01~DEV-05）：

- 开发经理将需求分解为多个开发任务单，各任务独立排期（DEV-01）
- 开发人员在线编制详细设计（DEV-02）
- 领导详细设计评审，通过/驳回（DEV-03）
- 开发执行，状态流转：待开发→开发中→开发完成（DEV-04）
- 任务单与需求申请单双向关联（DEV-05）
- 开发完成提测时自动触发测试任务单生成（衔接阶段 1.5）

### 4.3 状态机

```java
@Component
public class DevTaskStateMachine {

    private record StatusEvent(DevTaskStatusEnum status, DevTaskEventEnum event) {}

    private static final Map<StatusEvent, DevTaskStatusEnum> TRANSITIONS = Map.of(
            new StatusEvent(PENDING_DEV, START_DEV), IN_DEV,
            new StatusEvent(IN_DEV, SUBMIT_TEST), PENDING_TEST,
            new StatusEvent(PENDING_TEST, TEST_PASS), COMPLETED,
            new StatusEvent(PENDING_TEST, TEST_REJECT), IN_DEV  // 测试驳回返工
    );

    public DevTaskStatusEnum transit(DevTaskStatusEnum current, DevTaskEventEnum event) {
        DevTaskStatusEnum next = TRANSITIONS.get(new StatusEvent(current, event));
        if (next == null) {
            throw new CheckedException("非法状态转移: " + current + " + " + event);
        }
        return next;
    }
}
```

**状态流转图**：

```
PENDING_DEV ──开始开发──> IN_DEV ──提测──> PENDING_TEST ──测试通过──> COMPLETED
                                              │
                                              └──测试驳回──> IN_DEV（返工）
```

### 5.2 `DevTaskServiceImpl.java`（核心方法实现）

```java
@Service
@AllArgsConstructor
public class DevTaskServiceImpl extends ServiceImpl<DevTaskMapper, DevTask>
        implements DevTaskService {

    private final DevTaskStateMachine stateMachine;
    private final CodeGeneratorService codeGenerator;
    private final RequirementService requirementService;  // 回写需求状态
    private final ApprovalRecordMapper approvalRecordMapper;
    private final TodoService todoService;
    private final NotifyService notifyService;
    // 阶段1.5 将注入 TestTaskService，此处先声明接口依赖
    // private final TestTaskService testTaskService;

    /**
     * 任务分解：一个需求分解为多个任务单
     */
    @Override
    @Transactional(rollbackFor = Exception.class)
    public R createTasks(Long requirementId, List<DevTaskSaveDTO> tasks) {
        // 1. 校验需求存在且处于可分解状态
        Requirement req = requirementService.getById(requirementId);
        if (req == null) return R.failed("需求不存在");
        if (!RequirementStatusEnum.SCHEDULING.name().equals(req.getStatus())
                && !RequirementStatusEnum.DEVELOPING.name().equals(req.getStatus())) {
            return R.failed("需求当前状态不可分解任务");
        }

        // 2. 批量创建任务
        List<DevTask> entities = new ArrayList<>();
        for (DevTaskSaveDTO dto : tasks) {
            DevTask task = new DevTask();
            task.setTaskCode(codeGenerator.next("DEV"));
            task.setRequirementId(requirementId);
            task.setTaskName(dto.getTaskName());
            task.setTaskDesc(dto.getTaskDesc());
            task.setAssigneeId(dto.getAssigneeId());
            task.setPlanStartDate(dto.getPlanStartDate());
            task.setPlanEndDate(dto.getPlanEndDate());
            task.setReviewConclusion("PENDING");
            task.setStatus(DevTaskStatusEnum.PENDING_DEV.name());
            entities.add(task);
        }
        saveBatch(entities);

        // 3. 如果需求还处于排期中，自动流转到开发中
        if (RequirementStatusEnum.SCHEDULING.name().equals(req.getStatus())) {
            req.setStatus(RequirementStatusEnum.DEVELOPING.name());
            requirementService.updateById(req);
        }

        return R.ok(entities);
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public R saveDetailDesign(DevTaskDesignDTO dto) {
        DevTask task = getById(dto.getTaskId());
        if (task == null) return R.failed("任务不存在");
        // 详细设计可在待开发/开发中状态编制
        if (!DevTaskStatusEnum.PENDING_DEV.name().equals(task.getStatus())
                && !DevTaskStatusEnum.IN_DEV.name().equals(task.getStatus())) {
            return R.failed("当前状态不可编制详细设计");
        }
        task.setDetailDesign(dto.getDetailDesign());
        task.setReviewConclusion("PENDING");  // 重置为待评审
        updateById(task);
        return R.ok("详细设计已保存");
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public R submitDesignReview(Long taskId) {
        DevTask task = getById(taskId);
        if (task.getDetailDesign() == null || task.getDetailDesign().isBlank()) {
            return R.failed("请先编制详细设计");
        }
        task.setReviewConclusion("PENDING");
        updateById(task);

        // 生成设计评审待办给领导
        todoService.createTodo("REVIEW", "DEV_TASK", taskId,
                "待详细设计评审：" + task.getTaskCode(),
                "/admin/rm/dev-task/detail?id=" + taskId,
                SecurityUtils.getUser().getId());  // 实际应为领导角色
        return R.ok("已提交详细设计评审");
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public R designReview(DevTaskReviewDTO dto) {
        DevTask task = getById(dto.getTaskId());
        if (task == null) return R.failed("任务不存在");
        if (!"PENDING".equals(task.getReviewConclusion())) {
            return R.failed("该任务不在待评审状态");
        }

        // 记录评审记录
        ApprovalRecord record = new ApprovalRecord();
        record.setBillType("DEV_TASK");
        record.setBillId(task.getId());
        record.setNodeCode("DESIGN_REVIEW");
        record.setApproverId(SecurityUtils.getUser().getId());
        record.setConclusion(dto.getConclusion());
        record.setOpinion(dto.getOpinion());
        record.setApproveTime(LocalDateTime.now());
        approvalRecordMapper.insert(record);

        todoService.closeTodo("DEV_TASK", task.getId(), "REVIEW");

        if ("PASS".equals(dto.getConclusion())) {
            task.setReviewConclusion("PASS");
            // 评审通过后可开始开发
            if (DevTaskStatusEnum.PENDING_DEV.name().equals(task.getStatus())) {
                task.setStatus(DevTaskStatusEnum.IN_DEV.name());
                task.setActualStartDate(LocalDate.now());
            }
            updateById(task);
            // 通知开发人员
            notifyService.notifyUser(task.getAssigneeId(), "APPROVAL",
                    "详细设计评审通过：" + task.getTaskCode(), "可开始开发");
        } else {
            task.setReviewConclusion("FAIL");
            updateById(task);
            // 通知开发人员重新设计
            notifyService.notifyUser(task.getAssigneeId(), "REJECT",
                    "详细设计评审未通过：" + task.getTaskCode(), dto.getOpinion());
        }
        return R.ok("评审完成");
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public R startDev(Long taskId) {
        DevTask task = getById(taskId);
        DevTaskStatusEnum next = stateMachine.transit(
                DevTaskStatusEnum.valueOf(task.getStatus()),
                DevTaskEventEnum.START_DEV);
        task.setStatus(next.name());  // IN_DEV
        task.setActualStartDate(LocalDate.now());
        updateById(task);
        return R.ok("已开始开发");
    }

    /**
     * 开发完成提测
     * 触发：1. 任务状态→PENDING_TEST  2. 生成测试任务单  3. 通知测试人员
     */
    @Override
    @Transactional(rollbackFor = Exception.class)
    public R submitTest(Long taskId) {
        DevTask task = getById(taskId);
        if (!"PASS".equals(task.getReviewConclusion())) {
            return R.failed("详细设计评审未通过，不可提测");
        }
        DevTaskStatusEnum next = stateMachine.transit(
                DevTaskStatusEnum.valueOf(task.getStatus()),
                DevTaskEventEnum.SUBMIT_TEST);
        task.setStatus(next.name());  // PENDING_TEST
        task.setActualEndDate(LocalDate.now());
        updateById(task);

        // 触发测试任务单生成（阶段1.5实现，此处预留接口调用）
        // testTaskService.createFromDevTask(task);

        // 通知测试人员
        notifyService.notifyRole("rm_tester", "TEST",
                "开发任务已提测：" + task.getTaskCode(),
                "任务：" + task.getTaskName());
        return R.ok("已提测，测试任务单已生成");
    }

    @Override
    public IPage<DevTask> page(Page page, DevTaskQueryDTO query) {
        return baseMapper.selectPage(page,
                Wrappers.<DevTask>lambdaQuery()
                        .eq(query.getRequirementId() != null,
                                DevTask::getRequirementId, query.getRequirementId())
                        .eq(query.getAssigneeId() != null,
                                DevTask::getAssigneeId, query.getAssigneeId())
                        .eq(query.getStatus() != null,
                                DevTask::getStatus, query.getStatus())
                        .like(query.getKeyword() != null,
                                DevTask::getTaskName, query.getKeyword())
                        .orderByDesc(DevTask::getCreateTime));
    }

    @Override
    public R detail(Long id) {
        DevTask task = getById(id);
        if (task == null) return R.failed("任务不存在");

        DevTaskDetailVO vo = new DevTaskDetailVO();
        // 使用 BeanUtil 复制基础字段
        cn.hutool.core.bean.BeanUtil.copyProperties(task, vo);

        // 填充需求概要
        Requirement req = requirementService.getById(task.getRequirementId());
        vo.setRequirementCode(req != null ? req.getReqCode() : null);
        vo.setRequirementTitle(req != null ? req.getTitle() : null);

        // 填充负责人名称
        // vo.setAssigneeName(...) 通过 upms 查询

        // 填充评审记录
        List<ApprovalRecord> records = approvalRecordMapper.selectList(
                Wrappers.<ApprovalRecord>lambdaQuery()
                        .eq(ApprovalRecord::getBillType, "DEV_TASK")
                        .eq(ApprovalRecord::getBillId, id)
                        .orderByAsc(ApprovalRecord::getApproveTime));
        vo.setReviewRecords(records);

        return R.ok(vo);
    }
}
```

## 9. 与需求模块的联动

### 9.1 任务分解触发需求状态流转

当开发经理在排期中（SCHEDULING）的需求下分解任务时：

1. `createTasks()` 创建任务单
2. 需求状态从 `SCHEDULING` → `DEVELOPING`（自动流转）
3. 生成开发待办给各任务负责人

### 9.2 任务状态与需求状态的关系

| DevTask 状态 | 需求状态 | 说明 |
| --- | --- | --- |
| PENDING_DEV | DEVELOPING | 任务已分解，等待开发 |
| IN_DEV | DEVELOPING | 开发进行中 |
| PENDING_TEST | DEVELOPING | 已提测，需求仍为开发中 |
| COMPLETED | DEVELOPING → 可触发 TESTING | 当全部任务完成时触发需求状态变更 |

### 9.3 全部任务完成自动流转

在 `submitTest()` 或测试通过后，检查该需求下是否所有任务都已完成：

```java
/**
 * 检查需求下是否所有开发任务都已完成（COMPLETED）
 * 如果是，触发需求状态从 DEVELOPING → TESTING
 */
private void checkAllTasksCompleted(Long requirementId) {
    long pending = count(Wrappers.<DevTask>lambdaQuery()
            .eq(DevTask::getRequirementId, requirementId)
            .ne(DevTask::getStatus, DevTaskStatusEnum.COMPLETED.name()));
    if (pending == 0) {
        // 所有任务完成，触发需求状态流转
        requirementService.transitToTesting(requirementId);
    }
}
```

> 此方法在阶段 1.5 测试通过后调用，实现需求状态的自动联动。

## 10. 关键业务规则

| 规则 | 实现位置 | 说明 |
| --- | --- | --- |
| 仅排期中/开发中的需求可分解任务 | `createTasks()` | 校验需求状态 |
| 任务编号自动生成 | `createTasks()` | codeGenerator.next("DEV") |
| 详细设计评审通过后才可提测 | `submitTest()` | 校验 reviewConclusion=PASS |
| 驳回后可重新提交评审 | `submitDesignReview()` | reviewConclusion 重置为 PENDING |
| 评审记录只增不删 | `approvalRecordMapper` | 无 update/delete 接口 |
| 任务与需求双向关联 | `requirementId` 外键 + 需求详情页查询 | 双向可追溯 |
