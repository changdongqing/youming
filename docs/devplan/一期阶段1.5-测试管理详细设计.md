## 1. 阶段目标

实现测试管理模块的完整后端，覆盖 PRD §3.4 测试管理流程与 §4.4 全部功能项（TST-01~TST-07）：

- 测试用例库：编写、维护；用例关联需求（TST-01，支撑覆盖率统计）
- 测试任务单生成：开发完成提测后自动生成（TST-02）
- 测试执行与结果记录：按用例逐条执行（TST-03）
- Bug 管理：失败用例一键转 bug；当日 bug 不隔人天（TST-04）
- 测试通过/驳回：驳回时关联 bug 数量（TST-05）
- 测试工作量填报（TST-06，考核点 5）
- 操作指导书编制（TST-07，P1，一期可选）
- 测试通过 + 质量确认 → 需求状态自动完成（PRD 3.4 第 7 点）
- 用例覆盖率统计（考核点 6）

#### `TestCaseServiceImpl.java` — 覆盖率统计实现

```java
@Override
public R coverage() {
    // 方案：直接用 SQL 统计（通过 baseMapper.selectMaps 执行原生 SQL）
    // 或用 Wrapper 分别查询

    // 1. 查询所有开发中及以上的需求
    List<RequirementStatusEnum> activeStatuses = List.of(
            DEVELOPING, TESTING, PENDING_ACCEPTANCE, COMPLETED, RELEASED);

    long totalReq = requirementMapper.selectCount(
            Wrappers.<Requirement>lambdaQuery()
                    .in(Requirement::getStatus,
                            activeStatuses.stream().map(Enum::name).toList()));

    // 2. 查询有关联用例的需求数（去重）
    // SELECT COUNT(DISTINCT requirement_id) FROM rm_test_case
    // WHERE requirement_id IN (活跃需求ID列表) AND del_flag='0'
    List<TestCase> cases = testCaseMapper.selectList(
            Wrappers.<TestCase>lambdaQuery()
                    .isNotNull(TestCase::getRequirementId)
                    .select(TestCase::getRequirementId)
                    .groupBy(TestCase::getRequirementId));  // 去重
    long coveredReq = cases.size();

    // 3. 计算覆盖率
    BigDecimal rate = totalReq > 0
            ? BigDecimal.valueOf(coveredReq)
                    .multiply(BigDecimal.valueOf(100))
                    .divide(BigDecimal.valueOf(totalReq), 2, RoundingMode.HALF_UP)
            : BigDecimal.ZERO;

    CoverageVO vo = new CoverageVO();
    vo.setTotalReq(totalReq);
    vo.setCoveredReq(coveredReq);
    vo.setCoverageRate(rate);
    return R.ok(vo);
}
```

#### `TestTaskServiceImpl.java` — 核心方法实现

```java
@Service
@AllArgsConstructor
public class TestTaskServiceImpl extends ServiceImpl<TestTaskMapper, TestTask>
        implements TestTaskService {

    private final CodeGeneratorService codeGenerator;
    private final TestCaseService testCaseService;
    private final BugService bugService;
    private final TestExecutionMapper executionMapper;
    private final BugMapper bugMapper;
    private final DevTaskService devTaskService;
    private final RequirementService requirementService;
    private final TodoService todoService;
    private final NotifyService notifyService;

    /**
     * 从开发任务单创建测试任务单
     * 在 DevTaskService.submitTest() 中调用
     */
    @Override
    @Transactional(rollbackFor = Exception.class)
    public R createFromDevTask(DevTask devTask) {
        TestTask task = new TestTask();
        task.setTaskCode(codeGenerator.next("TST"));
        task.setDevTaskId(devTask.getId());
        task.setRequirementId(devTask.getRequirementId());
        task.setStatus("PENDING_TEST");
        save(task);

        // 为测试人员生成待办
        todoService.createTodoForRole("rm_tester", "TEST", "TEST_TASK", task.getId(),
                "待测试：" + task.getTaskCode() + "（来自 " + devTask.getTaskCode() + "）",
                "/admin/rm/test/task/detail?id=" + task.getId());
        return R.ok(task);
    }

    /**
     * 执行用例并记录结果
     */
    @Override
    @Transactional(rollbackFor = Exception.class)
    public R execute(TestExecutionDTO dto) {
        TestTask task = getById(dto.getTestTaskId());
        if (task == null) return R.failed("测试任务单不存在");

        // 如果任务还是待测试状态，自动流转为测试中
        if ("PENDING_TEST".equals(task.getStatus())) {
            task.setStatus("IN_TEST");
            task.setTestStartTime(LocalDateTime.now());
            updateById(task);
        }

        // 保存执行记录
        TestExecution exec = new TestExecution();
        exec.setTestTaskId(dto.getTestTaskId());
        exec.setCaseId(dto.getCaseId());
        exec.setResult(dto.getResult());
        exec.setRemark(dto.getRemark());
        exec.setExecuteTime(LocalDateTime.now());
        exec.setExecutorId(SecurityUtils.getUser().getId());
        executionMapper.insert(exec);

        return R.ok(exec);
    }

    /**
     * 失败用例一键转 bug
     */
    @Override
    @Transactional(rollbackFor = Exception.class)
    public R toBug(Long executionId, BugSaveDTO bugDto) {
        TestExecution exec = executionMapper.selectById(executionId);
        if (exec == null) return R.failed("执行记录不存在");
        if (!"FAIL".equals(exec.getResult())) {
            return R.failed("仅失败用例可转bug");
        }

        // 创建 bug
        Bug bug = new Bug();
        bug.setBugCode(codeGenerator.next("BUG"));
        bug.setTitle(bugDto.getTitle());
        bug.setTestTaskId(exec.getTestTaskId());
        bug.setExecutionId(executionId);
        // 冗余需求ID，便于统计
        TestTask task = getById(exec.getTestTaskId());
        bug.setRequirementId(task != null ? task.getRequirementId() : null);
        bug.setSource("TEST");  // 测试发现的bug
        bug.setSeverity(bugDto.getSeverity() != null ? bugDto.getSeverity() : "MAJOR");
        bug.setAssigneeId(bugDto.getAssigneeId());
        bug.setStatus("NEW");
        bug.setCreateDate(LocalDate.now());
        bugService.save(bug);

        // 回填执行记录的 bug_id
        exec.setBugId(bug.getId());
        executionMapper.updateById(exec);

        return R.ok(bug);
    }

    /**
     * 测试通过
     * 联动：1. 测试任务单状态→PASS  2. 开发任务状态→COMPLETED
     *       3. 检查需求下全部任务是否完成  4. 通知产品经理质量确认
     */
    @Override
    @Transactional(rollbackFor = Exception.class)
    public R pass(Long testTaskId) {
        TestTask task = getById(testTaskId);
        if (task == null) return R.failed("测试任务单不存在");

        // 校验：是否有未解决的 bug
        long unresolvedBugs = bugMapper.selectCount(
                Wrappers.<Bug>lambdaQuery()
                        .eq(Bug::getTestTaskId, testTaskId)
                        .notIn(Bug::getStatus, "CLOSED", "VERIFIED"));
        if (unresolvedBugs > 0) {
            return R.failed("存在 " + unresolvedBugs + " 个未解决bug，不可通过测试");
        }

        task.setStatus("PASS");
        task.setConclusion("PASS");
        task.setTestEndTime(LocalDateTime.now());
        updateById(task);

        // 联动开发任务状态
        DevTask devTask = devTaskService.getById(task.getDevTaskId());
        if (devTask != null) {
            devTask.setStatus(DevTaskStatusEnum.COMPLETED.name());
            devTaskService.updateById(devTask);
        }

        // 检查需求下全部任务是否完成
        checkAllTasksCompleted(task.getRequirementId());

        return R.ok("测试通过");
    }

    /**
     * 测试驳回（自动关联 bug 数量）
     * PRD TST-05
     */
    @Override
    @Transactional(rollbackFor = Exception.class)
    public R reject(Long testTaskId, String remark) {
        TestTask task = getById(testTaskId);
        if (task == null) return R.failed("测试任务单不存在");

        // 统计关联 bug 数量
        long bugCount = bugMapper.selectCount(
                Wrappers.<Bug>lambdaQuery()
                        .eq(Bug::getTestTaskId, testTaskId));

        task.setStatus("FAIL");
        task.setConclusion("FAIL");
        task.setTestEndTime(LocalDateTime.now());
        updateById(task);

        // 联动开发任务状态→返工（IN_DEV）
        DevTask devTask = devTaskService.getById(task.getDevTaskId());
        if (devTask != null) {
            devTask.setStatus(DevTaskStatusEnum.IN_DEV.name());
            devTaskService.updateById(devTask);
        }

        // 通知开发人员（含 bug 数量）
        String msg = String.format("测试未通过，关联bug %d 个：%s", bugCount, remark);
        notifyService.notifyUser(devTask.getAssigneeId(), "REJECT",
                "测试驳回：" + task.getTaskCode(), msg);

        return R.ok(Map.of("bugCount", bugCount, "message", "测试已驳回，关联bug " + bugCount + " 个"));
    }

    /**
     * 填报测试工作量
     */
    @Override
    public R saveWorkload(TestWorkloadDTO dto) {
        TestTask task = getById(dto.getTestTaskId());
        if (task == null) return R.failed("测试任务单不存在");
        task.setWorkload(dto.getWorkload());
        updateById(task);
        return R.ok("工作量已保存");
    }

    /**
     * 检查需求下全部开发任务是否完成
     * 如果全部完成，触发需求状态从 DEVELOPING → TESTING
     * 此时通知产品经理进行质量确认
     */
    private void checkAllTasksCompleted(Long requirementId) {
        long pending = devTaskService.count(
                Wrappers.<DevTask>lambdaQuery()
                        .eq(DevTask::getRequirementId, requirementId)
                        .ne(DevTask::getStatus, DevTaskStatusEnum.COMPLETED.name()));
        if (pending == 0) {
            // 所有任务完成，需求状态变为 TESTING
            // 此时产品经理进行质量确认（qualityConfirm）→ 自动流转到 PENDING_ACCEPTANCE
            Requirement req = requirementService.getById(requirementId);
            if (RequirementStatusEnum.DEVELOPING.name().equals(req.getStatus())) {
                req.setStatus(RequirementStatusEnum.TESTING.name());
                requirementService.updateById(req);
                // 通知产品经理质量确认
                notifyService.notifyRole("rm_product_approver", "APPROVAL",
                        "需求待质量确认：" + req.getReqCode(),
                        "所有开发任务测试通过，请进行质量确认");
            }
        }
    }

    @Override
    public R detail(Long id) {
        TestTask task = getById(id);
        if (task == null) return R.failed("测试任务单不存在");

        TestTaskDetailVO vo = new TestTaskDetailVO();
        BeanUtil.copyProperties(task, vo);

        // 填充执行记录列表
        List<TestExecution> executions = executionMapper.selectList(
                Wrappers.<TestExecution>lambdaQuery()
                        .eq(TestExecution::getTestTaskId, id)
                        .orderByAsc(TestExecution::getExecuteTime));
        vo.setExecutions(executions);

        // 填充 bug 列表
        List<Bug> bugs = bugMapper.selectList(
                Wrappers.<Bug>lambdaQuery()
                        .eq(Bug::getTestTaskId, id)
                        .orderByAsc(Bug::getCreateDate));
        vo.setBugs(bugs);

        // 统计 bug 数量
        vo.setBugCount((long) bugs.size());
        vo.setUnresolvedBugCount(bugs.stream()
                .filter(b -> !"CLOSED".equals(b.getStatus()) && !"VERIFIED".equals(b.getStatus()))
                .count());

        return R.ok(vo);
    }
}
```

## 5. 当日 Bug 提醒定时任务

### 5.1 `BugDailyReminderJob.java`

PRD 要求"bug 优先、测试 bug 不隔人天（当日 bug 当日处理）"。

```java
package com.pig4cloud.pig.rm.job;

import com.pig4cloud.pig.rm.api.entity.Bug;
import com.pig4cloud.pig.rm.mapper.BugMapper;
import com.pig4cloud.pig.rm.service.NotifyService;
import com.baomidou.mybatisplus.core.toolkit.Wrappers;
import lombok.AllArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.quartz.Job;
import org.quartz.JobExecutionContext;
import org.springframework.stereotype.Component;

import java.time.LocalDate;
import java.util.List;
import java.util.Map;
import java.util.stream.Collectors;

/**
 * 当日 Bug 提醒定时任务
 * 每日定时扫描未处理的当日 bug，通知处理人
 * 原则：bug 不隔人天
 */
@Slf4j
@Component
@AllArgsConstructor
public class BugDailyReminderJob implements Job {

    private final BugMapper bugMapper;
    private final NotifyService notifyService;

    @Override
    public void execute(JobExecutionContext context) {
        log.info("开始执行当日bug提醒任务...");

        // 查询当日未关闭的 bug
        List<Bug> todayBugs = bugMapper.selectList(
                Wrappers.<Bug>lambdaQuery()
                        .eq(Bug::getCreateDate, LocalDate.now())
                        .notIn(Bug::getStatus, "CLOSED")
                        .isNotNull(Bug::getAssigneeId));

        // 按处理人分组
        Map<Long, List<Bug>> byAssignee = todayBugs.stream()
                .collect(Collectors.groupingBy(Bug::getAssigneeId));

        // 为每个处理人生成通知
        byAssignee.forEach((userId, bugs) -> {
            String content = String.format("您有 %d 个当日bug未处理（bug不隔人天）：%s",
                    bugs.size(),
                    bugs.stream()
                            .map(b -> b.getBugCode() + ":" + b.getTitle())
                            .collect(Collectors.joining(", ")));
            notifyService.notifyUser(userId, "BUG_DAILY",
                    "当日bug未处理提醒", content);
        });

        log.info("当日bug提醒任务完成，通知了 {} 位处理人", byAssignee.size());
    }
}
```

```yaml
  jobs:
    - name: BugDailyReminderJob
      cron: "0 0 17 * * ?"
      group: rm
```

## 8. 全链路状态联动总结

测试管理是一期流程的"枢纽"，涉及需求、开发任务、测试任务、Bug 四个实体的状态联动：

```
开发任务 submitTest()
  → 测试任务单 createFromDevTask()     [生成 TST]
  → 测试人员 execute()                 [逐条执行用例]
  → 失败 → toBug()                     [一键转 BUG]
  → 全部通过 → pass()
      → 测试任务 PASS
      → 开发任务 COMPLETED
      → checkAllTasksCompleted()
          → 需求全部任务完成 → 需求 DEVELOPING→TESTING
          → 通知产品经理 qualityConfirm()
              → 需求 TESTING→PENDING_ACCEPTANCE
              → 通知发起人验收
  → 有未解决 bug → reject()
      → 测试任务 FAIL
      → 开发任务 IN_DEV（返工）
      → 通知开发人员（含 bug 数量）
```

## 9. 验收标准

| 序号 | 验收项 | 验证方法 |
| --- | --- | --- |
| AC-1.5.1 | 用例库 CRUD | 新增用例返回 case_code，可编辑删除 |
| AC-1.5.2 | 用例关联需求 | 用例 requirement_id 有值，覆盖率统计包含 |
| AC-1.5.3 | 提测自动生成测试任务单 | submitTest 后 test_task 表新增记录，status=PENDING_TEST |
| AC-1.5.4 | 测试执行记录 | execute 后 test_execution 表新增记录，测试任务 status=IN_TEST |
| AC-1.5.5 | 失败转 bug | toBug 后 bug 表新增，execution.bug_id 回填 |
| AC-1.5.6 | 测试通过联动 | pass 后测试任务 PASS，开发任务 COMPLETED |
| AC-1.5.7 | 全部任务完成触发需求状态 | 需求下全部任务 COMPLETED 后需求 status=TESTING |
| AC-1.5.8 | 质量确认触发待验收 | qualityConfirm 后需求 status=PENDING_ACCEPTANCE |
| AC-1.5.9 | 有未解决 bug 不可通过 | pass 时返回"存在 N 个未解决bug" |
| AC-1.5.10 | 测试驳回关联 bug 数量 | reject 返回 bugCount |
| AC-1.5.11 | 测试驳回联动返工 | reject 后开发任务 status=IN_DEV |
| AC-1.5.12 | 测试工作量填报 | workload 后测试任务 workload 有值 |
| AC-1.5.13 | 用例覆盖率统计 | coverage 返回 totalReq/coveredReq/coverageRate |
| AC-1.5.14 | 当日 bug 提醒 | Quartz 任务执行后 notify 表有 BUG_DAILY 类型通知 |
