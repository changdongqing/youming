## 1. 阶段目标

实现待办中心与消息通知模块，覆盖 PRD §4.7（MSG-01~MSG-03）：

- **我的待办（MSG-01）**：各角色待办事项聚合（待审批/待设计/待评审/待开发/待测试/待验收），区分执行人员与管理人员视角
- **流程消息通知（MSG-02）**：审批、驳回、提测、上线等关键节点通知
- **超期预警（MSG-03，P1）**：排期临近/超期提醒、当日 bug 未处理提醒

本阶段将之前 1.3~1.5 中作为依赖引用的 `TodoService` / `NotifyService` 落地实现。

### 4.2 `TodoServiceImpl.java`

```java
@Service
@AllArgsConstructor
public class TodoServiceImpl extends ServiceImpl<TodoMapper, Todo>
        implements TodoService {

    private final FlowNodeMapper flowNodeMapper;
    private final NotifyService notifyService;

    // 跨服务查询用户：单体模式直接注入 SysUserMapper/SysRoleMapper
    // 微服务模式通过 RemoteUserService Feign 调用
    // private final SysUserMapper sysUserMapper;
    // private final SysRoleMapper sysRoleMapper;

    @Override
    @Transactional(rollbackFor = Exception.class)
    public void createTodoForNode(FlowNode node, String billType, Long billId, String title) {
        // 根据 approver_type 解析审批人列表
        List<Long> approverIds = resolveApprovers(node, billType, billId);
        for (Long userId : approverIds) {
            createTodo(node.getNodeCode(), billType, billId, title,
                    buildUrl(billType, billId), userId);
        }
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public void createTodoForRole(String roleCode, String todoType, String billType,
                                  Long billId, String title, String url) {
        // 查询角色下所有用户
        List<Long> userIds = getUserIdsByRole(roleCode);
        for (Long userId : userIds) {
            createTodo(todoType, billType, billId, title, url, userId);
        }
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public void createTodo(String todoType, String billType, Long billId,
                          String title, String url, Long userId) {
        // 先关闭该单据同类型的旧待办（避免重复）
        closeTodo(billType, billId, todoType);

        Todo todo = new Todo();
        todo.setUserId(userId);
        todo.setTodoType(todoType);
        todo.setBillType(billType);
        todo.setBillId(billId);
        todo.setTitle(title);
        todo.setUrl(url);
        todo.setStatus("PENDING");
        // 截止时间：根据单据类型设置（如需求审批默认 2 天）
        todo.setDueTime(calculateDueTime(billType, todoType));
        save(todo);
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public void closeTodo(String billType, Long billId, String todoType) {
        // 将该单据该类型的 PENDING 待办批量标记为 CANCEL
        update(new com.baomidou.mybatisplus.core.toolkit.Wrappers.TodoLambdaUpdateWrapper()
                .eq(Todo::getBillType, billType)
                .eq(Todo::getBillId, billId)
                .eq(Todo::getTodoType, todoType)
                .eq(Todo::getStatus, "PENDING")
                .set(Todo::getStatus, "CANCEL"));
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public void closeAllTodo(String billType, Long billId) {
        update(new com.baomidou.mybatisplus.core.toolkit.Wrappers.TodoLambdaUpdateWrapper()
                .eq(Todo::getBillType, billType)
                .eq(Todo::getBillId, billId)
                .eq(Todo::getStatus, "PENDING")
                .set(Todo::getStatus, "CANCEL"));
    }

    @Override
    public IPage<TodoItemVO> myTodo(Page page, String todoType, String billType) {
        Long userId = SecurityUtils.getUser().getId();
        return baseMapper.selectTodoPage(page, userId, todoType, billType);
    }

    /**
     * 我的待办计数（按类型分组）
     */
    @Override
    public R myTodoCount() {
        Long userId = SecurityUtils.getUser().getId();
        List<Todo> todos = list(
                Wrappers.<Todo>lambdaQuery()
                        .eq(Todo::getUserId, userId)
                        .eq(Todo::getStatus, "PENDING"));

        // 按类型分组计数
        Map<String, Long> countByType = todos.stream()
                .collect(Collectors.groupingBy(Todo::getTodoType, Collectors.counting()));

        TodoCountVO vo = new TodoCountVO();
        vo.setTotal((long) todos.size());
        vo.setByType(countByType);
        return R.ok(vo);
    }

    @Override
    public R markDone(Long id) {
        Todo todo = getById(id);
        if (todo == null) return R.failed("待办不存在");
        todo.setStatus("DONE");
        updateById(todo);
        return R.ok("已完成");
    }

    // ========== 私有方法 ==========

    /**
     * 根据 FlowNode 的 approver_type 解析审批人
     */
    private List<Long> resolveApprovers(FlowNode node, String billType, Long billId) {
        String type = node.getApproverType();
        String ref = node.getApproverRef();

        return switch (type) {
            case "ROLE" -> getUserIdsByRole(ref);
            case "USER" -> List.of(Long.parseLong(ref));
            case "DEPT_LEADER" -> {
                // 获取发起人所在部门负责人
                // 需根据 billType + billId 查到发起人部门
                yield getDeptLeaderId(billType, billId);
            }
            case "INITIATOR_LEADER" -> {
                // 获取发起人所在部门负责人
                Long initiatorId = getInitiatorId(billType, billId);
                yield getDeptLeaderByUserId(initiatorId);
            }
            default -> List.of();
        };
    }

    /**
     * 查询角色下用户ID列表
     * 单体模式：直接查 sys_user_role
     */
    private List<Long> getUserIdsByRole(String roleCode) {
        // SELECT ur.user_id FROM sys_user_role ur
        // JOIN sys_role r ON ur.role_id = r.role_id
        // WHERE r.role_code = #{roleCode}
        // 简化实现：通过 MPJBaseMapper join 查询或直接 SQL
        // 此处省略具体实现，依赖 pig-upms 的表结构
        return List.of();
    }

    /**
     * 计算待办截止时间
     */
    private LocalDateTime calculateDueTime(String billType, String todoType) {
        // 审批类待办默认 2 天截止
        if ("APPROVE".equals(todoType) || "REVIEW".equals(todoType)) {
            return LocalDateTime.now().plusDays(2);
        }
        // 设计类待办默认 5 天
        if ("DESIGN".equals(todoType)) {
            return LocalDateTime.now().plusDays(5);
        }
        return null;  // 其他类型不限截止时间
    }

    /**
     * 构建跳转 URL
     */
    private String buildUrl(String billType, Long billId) {
        return switch (billType) {
            case "REQUIREMENT" -> "/admin/rm/requirement/detail?id=" + billId;
            case "DEV_TASK" -> "/admin/rm/dev-task/detail?id=" + billId;
            case "TEST_TASK" -> "/admin/rm/test/task/detail?id=" + billId;
            case "BUG" -> "/admin/rm/test/bug/detail?id=" + billId;
            default -> null;
        };
    }
}
```

```java
                        .eq(notifyType != null, Notify::getNotifyType, notifyType)

    }
```

```java
@Mapper
public interface TodoMapper extends MPJBaseMapper<Todo> {

    /**
     * 待办分页（关联单据编号）
     * 使用 MPJBaseMapper 的 join 能力或自定义 SQL
     */
    @org.apache.ibatis.annotations.Select("""
        SELECT t.*, CASE
                WHEN t.bill_type='REQUIREMENT' THEN r.req_code
                WHEN t.bill_type='DEV_TASK' THEN d.task_code
                WHEN t.bill_type='TEST_TASK' THEN tt.task_code
                WHEN t.bill_type='BUG' THEN b.bug_code
            END AS bill_code,
            (t.due_time IS NOT NULL AND t.due_time < now() AND t.status='PENDING') AS overdue
        FROM rm_todo t
        LEFT JOIN rm_requirement r ON t.bill_type='REQUIREMENT' AND t.bill_id=r.id
        LEFT JOIN rm_dev_task d ON t.bill_type='DEV_TASK' AND t.bill_id=d.id
        LEFT JOIN rm_test_task tt ON t.bill_type='TEST_TASK' AND t.bill_id=tt.id
        LEFT JOIN rm_bug b ON t.bill_type='BUG' AND t.bill_id=b.id
        WHERE t.user_id = #{userId} AND t.del_flag='0'
            AND (#{todoType} IS NULL OR t.todo_type = #{todoType})
            AND (#{billType} IS NULL OR t.bill_type = #{billType})
        ORDER BY t.create_time DESC
        """)
    IPage<TodoItemVO> selectTodoPage(Page page,
                                      @Param("userId") Long userId,
                                      @Param("todoType") String todoType,
                                      @Param("billType") String billType);
}
```

## 7. 超期预警定时任务

### 7.1 `OverdueWarningJob.java`

```java
@Slf4j
@Component
@AllArgsConstructor
public class OverdueWarningJob implements Job {

    private final TodoMapper todoMapper;
    private final RequirementMapper requirementMapper;
    private final DevTaskMapper devTaskMapper;
    private final NotifyService notifyService;

    @Override
    public void execute(JobExecutionContext context) {
        log.info("开始执行超期预警任务...");
        warnOverdueTodos();
        warnOverdueRequirements();
        warnOverdueDevTasks();
        log.info("超期预警任务完成");
    }

    /**
     * 1. 待办超期：due_time < now() 且 status=PENDING
     */
    private void warnOverdueTodos() {
        List<Todo> overdueTodos = todoMapper.selectList(
                Wrappers.<Todo>lambdaQuery()
                        .lt(Todo::getDueTime, LocalDateTime.now())
                        .eq(Todo::getStatus, "PENDING"));
        for (Todo todo : overdueTodos) {
            notifyService.notifyUser(todo.getUserId(), "OVERDUE",
                    "待办超期：" + todo.getTitle(),
                    "您的待办已超期，请尽快处理");
        }
    }

    /**
     * 2. 需求超期：expect_complete_date < today 且未完成
     */
    private void warnOverdueRequirements() {
        List<Requirement> overdueReqs = requirementMapper.selectList(
                Wrappers.<Requirement>lambdaQuery()
                        .lt(Requirement::getExpectCompleteDate, LocalDate.now())
                        .notIn(Requirement::getStatus, "COMPLETED", "RELEASED"));
        for (Requirement req : overdueReqs) {
            // 通知发起人和产品经理
            notifyService.notifyUser(req.getInitiatorId(), "OVERDUE",
                    "需求超期：" + req.getReqCode(),
                    "您的需求《" + req.getTitle() + "》已超过期望完成时间");
            notifyService.notifyRole("rm_product_approver", "OVERDUE",
                    "需求超期预警：" + req.getReqCode(),
                    "需求《" + req.getTitle() + "》已超期，请跟进");
        }
    }

    /**
     * 3. 开发任务超期：plan_end_date < today 且未完成
     */
    private void warnOverdueDevTasks() {
        List<DevTask> overdueTasks = devTaskMapper.selectList(
                Wrappers.<DevTask>lambdaQuery()
                        .lt(DevTask::getPlanEndDate, LocalDate.now())
                        .ne(DevTask::getStatus, "COMPLETED"));
        for (DevTask task : overdueTasks) {
            notifyService.notifyUser(task.getAssigneeId(), "OVERDUE",
                    "开发任务超期：" + task.getTaskCode(),
                    "任务《" + task.getTaskName() + "》已超过计划完成时间");
        }
    }
}
```

与设计计划 §8.1 一致，本阶段落地实现：

| 业务事件 | 调用方法 | 通知接收人 | 通知类型 |
| --- | --- | --- | --- |
| 需求提交 | `notifyApprovers()` | 审批人 | APPROVAL |
| 审批驳回 | `notifyUser()` | 发起人 | REJECT |
| 审批通过→待设计 | `notifyApprovers()` | 产品经理 | APPROVAL |
| 设计评审 | `notifyApprovers()` | 领导 | APPROVAL |
| 排期完成 | `notifyUser()` | 发起人 | APPROVAL |
| 开发提测 | `notifyRole("rm_tester")` | 测试人员 | TEST |
| 测试驳回 | `notifyUser()` | 开发人员 | REJECT |
| 测试通过+质量确认 | `notifyUser()` | 发起人 | APPROVAL |
| 当日 bug 未处理 | `BugDailyReminderJob` | bug 处理人 | BUG_DAILY |
| 排期超期 | `OverdueWarningJob` | 发起人/产品经理 | OVERDUE |
| 任务超期 | `OverdueWarningJob` | 开发人员 | OVERDUE |

## 9. 执行人员 vs 管理人员待办视图

PRD 要求"执行人员和管理人员查阅待办明细清晰"（待完善事项-2）：

| 视角 | 筛选条件 | 展示内容 |
| --- | --- | --- |
| 执行人员待办 | `user_id = 当前用户` | 我需要处理的待办（审批/设计/开发/测试/验收） |
| 管理人员待办 | `todo_type IN (APPROVE, REVIEW)` 且 `user_id = 当前用户` | 需要我审批/评审的事项 |

前端通过 Tab 切换，后端通过 `todoType` 筛选参数区分：

- 执行人员 Tab：不传 todoType（全部展示）或排除 APPROVE/REVIEW
- 管理人员 Tab：`todoType=APPROVE` 或 `todoType=REVIEW`

## 10. 验收标准

| 序号 | 验收项 | 验证方法 |
| --- | --- | --- |
| AC-1.6.1 | 待办自动生成 | 需求提交后审批人 `rm_todo` 表新增 PENDING 记录 |
