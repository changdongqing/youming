## 评审方法说明

本次评审非"通读文档找语病"，而是**以源码为锚核验文档论断**。对每条关键结论，在 public/pig 仓库执行 grep / 读源码确认：

- `db/pig.sql`：核实 AUTO_INCREMENT 处数、ON UPDATE 处数、表数、timestamp 列
- Mapper XML：核实总数（18）、含手写 SQL 数（8）、MySQL 专有函数（0 命中）
- `MybatisPlusMetaObjectHandler.java`：核实 insertFill/updateFill 实现
- `SysUser.java`：核实 updateTime 的 @TableField(fill) 实际值
- `DsTypeEnum.java`：核实 PG 枚举与 adapter
- 各 pom.xml：核实 postgresql 驱动、anyline 适配器依赖现状
- 文档引用的关键文件路径：逐条 stat 核实存在性

核验结果记录在各评审文档的"源码核验"小节，可作为文档可信度的证据链。
