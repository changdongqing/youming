### 04-🟡 N4 第 8.2 节补充 wall 独立 DataSource 配置示例

**位置**：第 8.2 节"风险"段之后

**改后追加**：

```java
// 当 Druid wall 拦截 Flyway 的 CREATE FUNCTION / CREATE TRIGGER 等 DDL 时，
// 为 Flyway 配置独立的无 wall DataSource：
@Bean
@FlywayDataSource
public DataSource flywayDataSource(DataSourceProperties properties) {
    return DataSourceBuilder.create()
        .url(properties.getUrl())
        .username(properties.getUsername())
        .password(properties.getPassword())
        .driverClassName(properties.getDriverClassName())
        .build();  // 不挂 wall/stat 等 Druid filter
}
```

> 或在 wall config 显式放行 DDL（`wall.config.alter-table-allow` / `none-base-statement-allow` 等，按实际拦截项调），二选一。
