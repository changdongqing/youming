# 可视化建模画布 操作指南

## 一、界面布局

可视化画布页面采用三栏布局 + 顶部工具栏 + 底部预览面板：

```
┌─────────────────────────────────────────────────────────────────┐
│ [项目选择器]  [自动布局]  [保存画布]  [序列化预览]               │  ← 顶部工具栏
├──────────┬──────────────────────────────────┬───────────────────┤
│ 模板侧栏  │                                  │  属性编辑抽屉      │
│          │         AntV X6 画布              │  （双击节点展开）  │
│ ▼分类模板 │     ┌─────────┐    ┌─────────┐  │                   │
│  设备     │     │  泵     │──sa│ 喷淋泵   │  │  类名: 喷淋泵     │
│  泵       │     └─────────┘    └─────────┘  │  IRI: .../Pump    │
│  喷淋泵   │        │ contains                │                   │
│ ▼属性模板 │     ┌─────────┐                   │  数据属性(5)      │
│  name     │     │ 泵房    │                   │  - 额定流量       │
│  price    │     └─────────┘                   │  - 扬程           │
│ ▼单位     │                                  │  - 功率           │
│  m        │     [dagre 自动布局]              │  ...              │
│  CNY      │                                  │                   │
├──────────┴──────────────────────────────────┴───────────────────┤
│ 序列化预览（CodeEditor, Turtle 语法高亮, 可折叠）                 │  ← 底部预览
│ @prefix owl: <...> . <...FireSprayPump> a owl:Class ; ...       │
└─────────────────────────────────────────────────────────────────┘
```

### 各区域说明

| 区域 | 位置 | 功能 |
|---|---|---|
| 顶部工具栏 | 页面顶部 | 项目选择、自动布局、保存画布状态、序列化预览开关 |
| 模板侧边栏 | 左侧 20% | 三 Tab：分类模板树 / 属性模板列表 / 单位列表，可拖拽 |
| X6 画布 | 中间 60% | 图形化建模工作区，类为节点、subClassOf 为继承边、对象属性为关联边 |
| 属性编辑抽屉 | 右侧 20% | 双击节点后展开，展示/编辑类信息和属性列表 |
| 序列化预览 | 底部可折叠 | 实时展示 Turtle/OWL XML 序列化结果（防抖 500ms） |

## 二、核心操作说明

### 2.1 选择项目

1. 在顶部工具栏的**项目选择器**下拉选择一个本体项目。
2. 选择后系统自动加载该项目下的所有类节点和关系边到画布，并恢复上次保存的画布布局。

> 如果项目下还没有类，画布会是空白的，需要从左侧模板侧边栏拖拽创建。

### 2.2 浏览模板侧边栏

左侧侧边栏有三个 Tab：

| Tab | 内容 | 来源 |
|---|---|---|
| 分类模板 | 分类模板树（如 设备 → 泵 → 喷淋泵），节点显示编码+名称+图标 | 治理域 Supply API `class-template/tree` |
| 属性模板 | 属性模板列表（如 name、price、flowRate），含类型/kind | 治理域 Supply API `property-templates` |
| 单位 | 单位列表（如 m、CNY），含 QUDT IRI | 治理域 Supply API `units` |

### 2.3 拖拽创建类节点（核心操作）

1. 在左侧**分类模板** Tab 中，找到要实例化的分类模板节点（如"喷淋泵"）。
2. **按住鼠标左键拖拽**该树节点，拖到中间画布区域后**松开鼠标**。
3. 系统弹出输入框，输入类的本地名（如 `FireSprayPump`）。
4. 点击确认后：
   - 后端自动调用 `POST /admin/ont/model/class` 创建类（含 templateCode 触发模板实例化）。
   - 后端自动从分类模板拉取继承属性，批量实例化为该类的数据属性/对象属性。
   - 画布上出现一个新的类节点。
   - 底部序列化预览自动刷新。

> 拖拽创建的类节点会自动带上 `ont:templateRef` 溯源注解和 `ont:classificationCode` 分类编码。

### 2.4 双击节点编辑属性

1. 在画布上**双击**任意类节点。
2. 右侧**属性编辑抽屉**展开，展示：
   - **类信息**：IRI（只读）、标签、模板溯源。
   - **数据属性 Tab**：该类下所有数据属性列表（属性名/XSD类型/单位）。
   - **对象属性 Tab**：该类下所有对象属性列表（属性名/标签/range）。
3. 在其他页面（如"本体属性建模"页）可以编辑属性的详细信息。

### 2.5 创建类之间的关系（边）

1. 将鼠标移到画布上的类节点上，节点边缘会出现**连接端口**。
2. **按住端口拖拽**，拉出一条连线到目标类节点。
3. 松开鼠标后，系统弹出选择：
   - **确认（OK）**：建立 `subClassOf`（继承关系，实线三角箭头）。
   - **取消（Cancel）**：建立对象属性（关联关系，虚线箭头），需输入属性名。
4. 后端自动校验（如 subClassOf 环路检测），成功后画布上出现新的边。

| 关系类型 | 边样式 | 后端接口 |
|---|---|---|
| subClassOf（继承） | 实线 + 三角箭头 | `POST /admin/ont/model/subclassof` |
| 对象属性（关联） | 虚线 + 普通箭头 + 属性名标签 | `POST /admin/ont/model/object-property` |

> 如果建立 subClassOf 会导致环路（如 A→B→A），后端会拒绝并返回错误，画布上的边自动删除。

### 2.6 自动布局

1. 点击顶部工具栏的**自动布局**按钮。
2. 系统使用 dagre 层次布局算法，将所有节点自上而下重新排列。
3. 继承关系和关联关系的边会自动路由（manhattan 路由）。

> 也可以手动拖拽节点调整位置。手动调整后点击"保存画布"可持久化布局。

### 2.7 保存画布状态

1. 调整完节点位置后，点击顶部工具栏的**保存画布**按钮。
2. 系统将画布的完整状态（节点位置、缩放比例）序列化为 JSON，保存到后端 `ont_model_canvas_state` 表。
3. 每个用户独立保存，下次打开同一项目时自动恢复上次的布局。

### 2.8 查看序列化预览

1. 底部**序列化预览面板**默认展开，展示当前项目的 Turtle 序列化结果。
2. 可以切换格式：**Turtle**（`.ttl`）或 **OWL XML**（`.owl.xml`）。
3. 画布上的任何操作（建类、建关系等）都会触发防抖 500ms 后自动刷新预览。

> 预览内容包含 `@prefix` 命名空间声明 + `owl:Class` + `owl:DatatypeProperty` + `owl:ObjectProperty` + `rdfs:subClassOf` + `ont:xxx` 注解。

## 三、节点和边的视觉含义

### 类节点

```
┌─────────────────────┐
│ 📦 喷淋泵            │  ← 图标 + 标签（label 或 localName）
│ 30-01-01  [模板]     │  ← 分类编码 + 模板溯源标记
└─────────────────────┘
```

- 节点边框颜色来自类的 `color` 字段（默认蓝色 `#409eff`）。
- 图标来自类的 `icon` 字段（默认 📦）。
- `[模板]` 标签表示该类是基于分类模板创建的（有 templateCode）。

### 继承边（subClassOf）

```
  子类 ──────▶ 父类
        实线 + 三角箭头
```

表示 `rdfs:subClassOf` 关系，子类继承父类。

### 关联边（对象属性）

```
  域类 ─ ─ ─ ▶ 值域类
     contains
  虚线 + 普通箭头 + 属性名标签
```

表示对象属性（如 `contains`），连接 domain 类和 range 类。

## 四、完整操作流程示例

以"创建消防设备本体"为例：

1. **选择项目**：在顶部选择"消防设备本体"项目。
2. **拖拽创建类**：从左侧分类模板树拖拽"喷淋泵"到画布，输入类名 `FireSprayPump`，系统自动实例化 5 个属性。
3. **再创建一个类**：拖拽"泵房"到画布，输入类名 `FirePumpRoom`。
4. **建立关联**：从 `FirePumpRoom` 节点拖出连线到 `FireSprayPump`，选择"对象属性"，输入属性名 `contains`。
5. **双击查看**：双击 `FireSprayPump` 节点，右侧抽屉展示 5 个数据属性。
6. **查看序列化**：底部预览面板自动展示 Turtle 序列化结果。
7. **保存布局**：调整节点位置后点击"保存画布"。

## 五、注意事项

- **前置条件**：需要先在"本体项目管理"中创建项目，并在"本体类建模"中创建类后，画布才有内容可渲染。
- **权限要求**：查看画布需 `ont_canvas_view` 权限；保存画布需 `ont_canvas_manage` 权限；拖拽建类需 `ont_class_model_manage` 权限。
- **性能限制**：画布建议 ≤100 节点。超过时 dagre 布局可能变慢，建议拆分项目。
- **画布是增值层**：所有建模操作也可通过"本体类建模"和"本体属性建模"的表单页面完成，画布只是更直观的图形化操作方式。
