# 火灾报警系统业务场景

## 设备相关

包括感烟探测器、感温探测器、手动报警按钮等火警探测设备，会触发“事件状态”，“事件状态”包括“火警、故障、屏蔽、正常”

## 工单相关

* 服务申请工单：主要是用于设备故障、屏蔽后发起服务申请，服务申请工单支持派单生成服务工单；
* 服务工单：主要是用于维修工人接单或者被派单后，执行相关的服务，比如维修、更换等；
* 火警现场复核工单：主要用于感应设备触发火警后，派单给现场附近的人员尽快到现场确认火警的真实情况，反馈结果后，由值班人员根据反馈结果处置。
* 火警值班处置工单：主要用于感应设备触发火警后，派单给值班室值班人员，值班人员根据现场反馈的复核反馈结果，进行处置，主要是火警结论的提报，如果是真实火警，则立即启动救火预案（启动救火预案这事暂且不管）；

## 设备告警与工单关联关系

如工单相关中描述，其中的设备故障、屏蔽、火警信息均由设备的“事件状态”物联采集实时上报。

## 设备采集数据与维保质量关联关系

* 火警探测设备维保：必须在维保时间段内”事件状态“按顺序出现过”正常（初始状态，可以不是出现过，但是以此状态为基础）、火警、正常“方为合格，否则为不合格；
