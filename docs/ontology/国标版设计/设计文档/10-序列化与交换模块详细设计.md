## 1. 评审结论与设计边界

### 1.1 现状评审

截至本设计时点，前述9个模块已全部落地：命名空间（6条预置）、实体类型（86个核心类型+继承树+不相交+等价类）、数据属性（47个核心属性+值域规范+单位引用）、对象属性（34个核心属性+域值域+语义标记）、公理规则（12条内置规则+24条目标绑定）、实体对象实例（29个附录D实例+83条数据值+39条对象断言）、校验引擎（5类执行器+SHACL验证器+OWL推理机+报告持久化）均已通过 Flyway V4–V11 迁移脚本预置并验证。但代码库中存在以下序列化与交换缺口：

| 缺口 | 现状 | 影响 |
|------|------|------|
| **无序列化控制器** | 后端无 `/ontology/serialization` 控制器，`OntologyModelAssembler` 已能构建 Jena `Model` 但无导出端点 | PRD §4.8 多格式导出无法运行，§5.3 附录D导出验证无法执行 |
| **Model 组装不完整** | `OntologyModelAssembler.buildSchemaModel()` 仅组装类声明+继承+不相交，缺失数据属性声明、对象属性声明、公理规则（OWL公理文本）、等价类声明 | Schema层导出缺失大量OWL定义，不满足§5.3"Schema+Data一体导出" |
| **前缀映射缺失** | `buildSchemaModel`/`buildInstanceModel` 均未调用 `setNsPrefix`，导出Turtle无 `@prefix` 声明 | 导出文本不符合国标格式要求，与附录D Turtle不可比 |
| **日期格式不完整** | `createLiteralNode` 已实现 `YYYYMMDD→YYYY-MM-DD` 转换用于 `xsd:date`，但未处理 `REFERENCE_ONLY` 声明模式实例的过滤 | 导出可能包含引用型实例的非完整三元组 |
| **别名映射未落地** | `OntDataProperty` 有 `preferredAlias`/`standardIri` 字段，`unit`↔`measurementUnit` 别名映射在设计文档05/08中提及，但序列化时未按别名输出 | 导出的谓词IRI可能不符合附录D期望（如输出 `unit` 而非 `measurementUnit`） |
| **无导入能力** | 无RDF文件解析器，无法将外部 Turtle/JSON-LD 导入为内部模型 | PRD §4.8 多格式导入未落地 |
| **无导出前置校验** | PRD §6.3 要求"导出前强制全量校验；Error未清零时禁用发布导出"，但无导出前校验拦截逻辑 | 违规本体可能被导出，不满足§3.3"校验前置与阻断" |
| **无导出记录留痕** | PRD §3.3 要求"导入导出审计可追溯"，但无导出记录表 | 导出操作无审计追踪 |
| **校验引擎Model组装器代码重复** | `OntologyModelAssembler.createLiteralNode()` 与 `DataGraphBuilder.createLiteralNode()` 完全重复 | 序列化模块需复用而非再复制一份 |

### 1.2 优化结论

| 级别 | 评审发现 | 优化结论 |
|------|----------|----------|
| P0 | `OntologyModelAssembler` 是校验引擎模块（09）的内部组件，其 `buildSchemaModel`/`buildInstanceModel` 方法仅服务于校验场景，Schema组装不完整（缺数据属性/对象属性/公理声明），不适合直接用于序列化导出 | 序列化模块新建 `OntologyModelExporter`（序列化专用Model组装器），与校验引擎的 `OntologyModelAssembler` 职责分离；序列化组装器复用 `createLiteralNode` 逻辑但扩展为完整Schema+Data组装 |
| P0 | 导出前需强制全量校验（PRD §3.3/§6.3），但校验是异步操作（§09设计），导出是同步操作 | 导出前检查**最近一次全量校验报告**：若不存在或 `conforms=false`（存在VIOLATION），则拦截导出并返回校验报告引用；用户可选择"仅导出"跳过（需 `ontology_export_force` 权限） |
| P0 | 附录D期望Turtle使用 `measurementUnit` 而非 `unit`，但数据属性表预置的是 `standardIri`（国标原名）与 `preferredAlias`（示例别名），导出须按策略选择 | 导出请求支持 `predicateStrategy` 参数：`PREFERRED_ALIAS`（默认，输出 `preferredAlias`/`iri`，附录D兼容）/ `STANDARD_IRI`（输出 `standardIri`，国标严格口径）/ `INTERNAL_IRI`（输出内部 `iri`） |
| P0 | 前缀映射缺失导致导出Turtle无 `@prefix` 声明 | 序列化组装器统一注册前缀映射：从 `ont_namespace` 表加载所有命名空间，按 `prefix→uri` 注册到 Jena `Model`；同时注册标准前缀（rdf/rdfs/xsd/owl/sh） |
| P1 | 导入RDF文件需解析为内部模型并写入关系库，但当前无导入解析器 | 本期导入范围限定为**实例数据导入**（Schema层由预置+扩展管理模块维护，不通过RDF导入覆盖）；解析器使用 Jena `RDFParser` 解析为 `Model`，再逐条映射到 `ont_entity_instance`/`ont_instance_data_value`/`ont_instance_object_relation` |
| P1 | 导出范围需支持按模块/子树筛选（PRD §4.8"按模块序列化"） | 导出请求支持 `scope` 参数：`FULL`（整体Schema+Data）/ `SCHEMA_ONLY`（仅Schema）/ `INSTANCE_ONLY`（仅实例）/ `INSTANCE_SUBTREE`（按实体类型子树过滤实例） |
| P1 | 导出审计需留痕（PRD §3.3"审计可追溯"） | 新增 `ont_serialization_log` 表记录每次导出/导入操作（操作类型、格式、范围、文件大小、操作人、时间、校验报告引用） |
| P2 | `OntologyModelAssembler.getCoreNamespaceUri()` 为硬编码桩 | 序列化模块的 `OntologyModelExporter` 从 `ont_namespace` 表动态加载命名空间，不依赖硬编码；校验引擎的硬编码桩后续由本模块的 `NamespacePrefixResolver` 统一替代（本期不强制重构09模块） |
| P2 | 附录D验证需"序列化等价"比对（PRD §5.4），但自动语义比对工具复杂 | 本期提供"导出Turtle预览"+"手动比对"方式，不实现自动语义等价比对工具；通过种子数据预置+验收测试断言关键三元组存在性来保证等价性 |

### 1.3 本期范围

**本期包含：**

1. 序列化专用Model组装器（`OntologyModelExporter`）——完整Schema+Data组装，含前缀映射
2. 多格式导出引擎（Turtle / JSON-LD / RDF/XML / N-Triples）
3. 导出前置校验拦截（检查最近全量校验报告）
4. 谓词策略选择（PREFERRED_ALIAS / STANDARD_IRI / INTERNAL_IRI）
5. 导出范围控制（FULL / SCHEMA_ONLY / INSTANCE_ONLY / INSTANCE_SUBTREE）
6. 实例数据导入解析器（Turtle / JSON-LD / RDF/XML → 关系库写入）
7. 导入预检与映射报告（解析后展示IRI映射、冲突检测、预览）
8. 导出/导入审计日志表（`ont_serialization_log`）
9. 序列化REST API（导出、导入、预览、下载）
10. 前端导入导出页面（格式选择、范围配置、预览、下载、上传）
11. Flyway V12 迁移脚本（审计表 + 菜单权限）
12. 附录D导出验收种子数据与自动化测试

**本期不包含：**

- Schema层RDF导入（Schema由预置+扩展管理模块维护，不通过RDF文件覆盖）
- Triplestore双写（序列化只读关系库组装Model，不持久化到Jena TDB/GraphDB）
- 自动语义等价比对工具（通过测试断言保证等价性）
- 批量异步导出任务队列（本期导出为同步操作，10万实例级在30s内可接受）
- SPARQL查询端点（属可视化模块或后续扩展）
- 导入时的自动SHACL校验（导入写入后由用户手动触发校验）
- 跨本体工程的实例合并导入（限定同一 `ontologyId` 内导入）

### 1.5 权威语义口径

1. 序列化导出是**只读操作**：不修改关系库任何数据，仅在内存中构建 Jena `Model` 并序列化为文本。
2. 序列化导出的Model须包含**完整本体定义**：Schema层（`owl:Class`声明、`rdfs:subClassOf`、`owl:disjointWith`、`owl:equivalentClass`、`owl:DatatypeProperty`声明、`rdfs:domain`/`rdfs:range`、`owl:ObjectProperty`声明及语义标记、`owl:FunctionalProperty`等、SHACL Shapes）+ Data层（`rdf:type`断言、数据属性值、对象属性断言）。
3. 前缀映射从 `ont_namespace` 表动态加载，不硬编码；标准前缀（rdf/rdfs/xsd/owl/sh）为固定常量。
4. 日期型字面量导出为 `xsd:date` 词法形式（`YYYY-MM-DD`），平台内部存储为 `YYYYMMDD`，转换在组装Model时完成（复用09模块 `createLiteralNode` 已有逻辑）。
5. UNIT_REF类型值导出为单位符号字面量（如 `"%"`、`"V"`），从 `ont_instance_data_value.literal_symbol` 或 `ont_unit.unit_symbol` 读取。
6. 谓词IRI策略：`PREFERRED_ALIAS`（默认）输出数据属性的 `preferredAlias`（若非空）否则输出 `iri`；`STANDARD_IRI` 输出 `standardIri`（若非空）否则输出 `iri`；`INTERNAL_IRI` 始终输出 `iri`。对象属性同理（对象属性无 `preferredAlias`/`standardIri` 字段，始终使用 `iri`）。
7. 导出前校验拦截：若最近一次全量校验报告 `conforms=false` 或不存在报告，默认拦截导出；用户可通过 `force=true` 参数 + `ontology_export_force` 权限跳过。
8. 导入是**写入操作**：将RDF文件解析为实例数据并写入 `ont_entity_instance`/`ont_instance_data_value`/`ont_instance_object_relation`，需 `ontology_import_add` 权限。
9. 导入范围限定为实例数据：Schema层三元组（`owl:Class`/`owl:DatatypeProperty`/`owl:ObjectProperty`声明）在导入时被识别并跳过（Schema由预置+扩展管理维护）。
10. 导入采用**预检→确认→写入**两阶段：先解析并生成映射预览（不写入），用户确认后再执行写入。

### 2.2 核心设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 导出数据源 | PostgreSQL 关系库（只读） | 与模块08/09一致，不引入 Triplestore 双写；Jena Model 在内存中临时构建，导出完即释放 |
| Model组装器 | 新建 `OntologyModelExporter`（独立于09的 `OntologyModelAssembler`） | 09的Assembler仅组装校验所需的最小Model（类层次+不相交+实例三元组），序列化需完整Schema+Data；职责分离避免互相影响 |
| RDF序列化 | Jena `RDFWriter` / `RDFDataMgr.write()` | Jena 5.5.0 原生支持 Turtle/JSON-LD/RDF/XML/N-Triples 四种格式，无需额外依赖 |
| RDF导入解析 | Jena `RDFParser` | Jena 5.5.0 原生支持多格式解析，统一API |
| 导出前置校验 | 检查最近全量校验报告 | 复用09模块的 `ont_validation_report` 表，不重复执行校验；若报告不存在或 `conforms=false` 则拦截 |
| 导出范围控制 | `scope` 参数 + 实体类型子树过滤 | 满足PRD §4.8"按模块序列化"需求，子树过滤复用04模块的继承层次 |
| 谓词IRI策略 | `predicateStrategy` 参数 | 兼容附录D示例（`measurementUnit`）与国标严格口径（`unit`），不硬编码 |
| 前缀映射 | 从 `ont_namespace` 表动态加载 | 命名空间可由用户扩展（03模块），不硬编码；标准前缀（rdf/rdfs/xsd/owl/sh）为常量 |
| 导入流程 | 两阶段（预检→确认） | PRD §6.3要求"导入先预检映射"，避免直接写入导致脏数据 |
| 导入范围 | 仅实例数据 | Schema层由预置+扩展管理模块维护，RDF导入不覆盖Schema；Schema三元组在导入时识别并跳过 |
| 导出/导入审计 | `ont_serialization_log` 表 | PRD §3.3"审计可追溯"，记录每次操作 |
| 同步导出 | 不使用异步队列 | 10万实例级导出在30s内可接受（PRD性能要求），同步操作简化交互；后续如需可升级为异步 |
| 单位符号序列化 | 从 `literal_symbol` 或 `ont_unit.unit_symbol` 读取 | `literal_symbol` 是导入时的快照（08模块设计），导出时优先使用；若为空则回退查 `ont_unit` |

## 3. 导出 Model 组装设计

### 3.1 OntologyModelExporter

> 序列化专用 Model 组装器，与校验引擎的 `OntologyModelAssembler` 职责分离。
> 组装完整本体 Model：Schema层（类/属性/公理声明）+ Data层（实例三元组）。

```java
/**
 * 本体模型导出组装器
 * <p>
 * 从关系库读取 Schema 和实例数据，组装为完整的 Jena {@link Model}。
 * 与校验引擎的 {@code OntologyModelAssembler} 职责分离：
 * - 本组装器输出完整 OWL 本体定义（类/属性/公理/实例），用于序列化导出；
 * - 校验引擎的 Assembler 仅组装校验所需的最小 Model（类层次+不相交+实例三元组）。
 * </p>
 * <p>
 * 每次调用创建独立的 Model，不跨本体工程共享，避免并发污染。
 * </p>
 */
@Slf4j
@Component
@RequiredArgsConstructor
public class OntologyModelExporter {

    private final OntNamespaceMapper namespaceMapper;
    private final OntEntityTypeMapper entityTypeMapper;
    private final OntEntityTypeHierarchyMapper hierarchyMapper;
    private final OntEntityTypeDisjointMapper disjointMapper;
    private final OntEntityTypeEquivalentMapper equivalentMapper;
    private final OntEntityTypeLabelMapper labelMapper;
    private final OntDataPropertyMapper dataPropertyMapper;
    private final OntDataPropertyLabelMapper dataPropertyLabelMapper;
    private final OntDataPropertyEnumMapper dataPropertyEnumMapper;
    private final OntObjectPropertyMapper objectPropertyMapper;
    private final OntObjectPropertyLabelMapper objectPropertyLabelMapper;
    private final OntObjectPropertyDomainMapper objectPropertyDomainMapper;
    private final OntObjectPropertyRangeMapper objectPropertyRangeMapper;
    private final OntAxiomRuleMapper axiomRuleMapper;
    private final OntEntityInstanceMapper instanceMapper;
    private final OntInstanceDataValueMapper dataValueMapper;
    private final OntInstanceObjectRelationMapper relationMapper;
    private final OntUnitMapper unitMapper;
    private final NamespacePrefixResolver prefixResolver;
    private final PredicateStrategyResolver predicateResolver;

    /**
     * 组装完整本体 Model（Schema + Data）
     *
     * @param ontologyId       本体工程ID
     * @param scope            导出范围
     * @param predicateStrategy 谓词IRI策略
     * @param targetTypeFilter 实例子树过滤的实体类型ID（scope=INSTANCE_SUBTREE 时非空）
     * @return 完整 Jena Model（含前缀映射）
     */
    public Model buildCompleteModel(Long ontologyId,
                                     ExportScope scope,
                                     PredicateStrategy predicateStrategy,
                                     Long targetTypeFilter) {
        Model model = ModelFactory.createDefaultModel();

        // 1. 注册前缀映射
        prefixResolver.registerPrefixes(model);

        // 2. 组装 Schema 层（根据 scope 决定是否包含）
        if (scope != ExportScope.INSTANCE_ONLY) {
            buildSchemaLayer(model, ontologyId, predicateStrategy);
        }

        // 3. 组装 Data 层（根据 scope 决定是否包含）
        if (scope != ExportScope.SCHEMA_ONLY) {
            buildDataLayer(model, ontologyId, predicateStrategy, scope, targetTypeFilter);
        }

        return model;
    }

    /**
     * 组装 Schema 层
     */
    private void buildSchemaLayer(Model model, Long ontologyId,
                                   PredicateStrategy predicateStrategy) {
        buildClassDeclarations(model, ontologyId);
        buildDataPropertyDeclarations(model, ontologyId, predicateStrategy);
        buildObjectPropertyDeclarations(model, ontologyId);
        buildAxiomDeclarations(model, ontologyId);
    }

    /**
     * 组装 Data 层
     */
    private void buildDataLayer(Model model, Long ontologyId,
                                 PredicateStrategy predicateStrategy,
                                 ExportScope scope, Long targetTypeFilter) {
        // 加载实例（按子树过滤或全量）
        List<OntEntityInstance> instances = loadInstances(ontologyId, scope, targetTypeFilter);
        if (instances.isEmpty()) return;

        Map<Long, String> instanceIdToIri = instances.stream()
            .collect(Collectors.toMap(OntEntityInstance::getId, OntEntityInstance::getIri));

        buildInstanceTypeTriples(model, instances, instanceIdToIri);
        buildDataValueTriples(model, instances, instanceIdToIri, predicateStrategy);
        buildObjectRelationTriples(model, instances, instanceIdToIri, predicateStrategy);
    }
}
```

### 3.2 Schema 层组装明细

#### 3.2.1 类声明（`buildClassDeclarations`）

```
对 ontology_id 下的所有 ont_entity_type：
  1. <iri> rdf:type owl:Class
  2. <iri> rdfs:label "label"  （从 ont_entity_type_label 加载，按 locale）
  3. <iri> rdfs:comment "definition"  （若 definition 非空）
  4. 若 isAbstract='1'，添加 <iri> a owl:Class 且声明为抽象类
     （Jena无直接"abstract class"声明，通过OWL建模约定：不实例化的类即为抽象类）
```

#### 3.2.2 继承关系（`buildClassDeclarations` 续）

```
对 ont_entity_type_hierarchy 的所有 parent→child 对：
  <childIri> rdfs:subClassOf <parentIri>
```

#### 3.2.3 不相交声明

```
对 ont_entity_type_disjoint 的所有 typeA↔typeB 对：
  <iriA> owl:disjointWith <iriB>
  （单向声明即可，OWL语义下 disjointWith 是对称的）
```

#### 3.2.4 等价类声明

```
对 ont_entity_type_equivalent 的所有 entityId↔equivalentId 对：
  <iriA> owl:equivalentClass <iriB>
```

#### 3.2.5 数据属性声明（`buildDataPropertyDeclarations`）

```
对 ontology_id 下的所有 ont_data_property：
  1. <predicateIri> rdf:type owl:DatatypeProperty
     （predicateIri 由 PredicateStrategyResolver 按策略解析）
  2. <predicateIri> rdfs:label "label"
  3. <predicateIri> rdfs:comment "definition"
  4. <predicateIri> rdfs:domain <domainEntityTypeIri>
  5. <predicateIri> rdfs:range <xsdType>
     （baseType → XSD映射：BOOLEAN→xsd:boolean, DATE→xsd:date,
       NUMERIC→xsd:decimal(DECIMAL)/xsd:integer(INTEGER),
       TEXT→xsd:string, URI→xsd:anyURI）
  6. 若 isUnique='1'，添加 <predicateIri> a owl:FunctionalProperty
     （唯一性约束通过 FunctionalProperty 表达）
```

#### 3.2.6 对象属性声明（`buildObjectPropertyDeclarations`）

```
对 ontology_id 下的所有 ont_object_property：
  1. <iri> rdf:type owl:ObjectProperty
  2. <iri> rdfs:label "label"
  3. <iri> rdfs:comment "definition"
  4. <iri> rdfs:domain <domainEntityTypeIri>
     （从 ont_object_property_domain 加载，多值用 owl:unionOf 表达）
  5. <iri> rdfs:range <rangeEntityTypeIri>
     （从 ont_object_property_range 加载，多值用 owl:unionOf 表达）
  6. 若 isFunctional='1'，添加 <iri> a owl:FunctionalProperty
  7. 若 isInverseFunctional='1'，添加 <iri> a owl:InverseFunctionalProperty
  8. 若 isTransitive='1'，添加 <iri> a owl:TransitiveProperty
  9. 若 isSymmetric='1'，添加 <iri> a owl:SymmetricProperty
  10. 若 inverseOfId 非空，添加 <iri> owl:inverseOf <inverseIri>
```

#### 3.2.7 公理声明（`buildAxiomDeclarations`）

```
对 ontology_id 下 ont_axiom_rule 中 owl_axiom 非空的规则：
  若 owlAxiom 为合法 Turtle 片段，解析并合并到 Model：
    model.read(new StringReader(owlAxiom), null, "TURTLE")
  解析失败时记录警告日志，不中断导出
```

### 3.3 Data 层组装明细

#### 3.3.1 实例类型三元组

```
对每个 ont_entity_instance（declaration_mode=EXPLICIT）：
  <instanceIri> rdf:type <rdfTypeIri>
  <instanceIri> rdfs:label "label"  （若 label 非空）

  注意：declaration_mode=REFERENCE_ONLY 的实例不输出 rdf:type 三元组
  （该类实例仅作为对象属性的客体被引用，无独立声明）
```

#### 3.3.2 数据属性值三元组

```
对每个实例的 ont_instance_data_value：
  1. 解析谓词IRI：predicateResolver.resolve(dataProperty, strategy)
  2. 解析字面量：
     - literalType=STRING → model.createLiteral(value)
     - literalType=INTEGER → model.createTypedLiteral(Long.parseLong(value), XSDDatatype.XSDinteger)
     - literalType=DECIMAL → model.createTypedLiteral(new BigDecimal(value), XSDDatatype.XSDdecimal)
     - literalType=BOOLEAN → model.createTypedLiteral(Boolean.parseBoolean(value), XSDDatatype.XSDboolean)
     - literalType=DATE → YYYYMMDD→YYYY-MM-DD，model.createTypedLiteral(dateStr, XSDDatatype.XSDdate)
     - literalType=URI → model.createResource(value)
     - UNIT_REF模式 → model.createLiteral(literalSymbol)
       （literalSymbol 优先，为空则查 ont_unit.unit_symbol）
  3. <instanceIri> <predicateIri> <literal>
```

#### 3.3.3 对象属性断言三元组

```
对每个实例的 ont_instance_object_relation（作为主体）：
  1. 解析谓词IRI：objectProperty.getIri()（对象属性始终用内部IRI）
  2. 解析客体IRI：
     - objectKind=INSTANCE → instanceIdToIri.get(objectInstanceId)
     - objectKind=ENTITY_TYPE → entityTypeIri.get(objectEntityTypeId)
  3. <subjectIri> <predicateIri> <objectIri>

  注意：客体实例可能不在当前导出范围内（scope=INSTANCE_SUBTREE 时），
  此时客体IRI仍输出（引用外部资源的IRI），但客体实例的 rdf:type 声明可能不包含在导出中。
  这是预期行为——导出的是"以主体实例为中心的关系图"。
```

### 3.4 前缀映射解析器

```java
/**
 * 命名空间前缀映射解析器
 * <p>
 * 从 ont_namespace 表加载所有命名空间，注册到 Jena Model 的前缀映射。
 * 同时注册标准前缀（rdf/rdfs/xsd/owl/sh）。
 * </p>
 */
@Component
@RequiredArgsConstructor
public class NamespacePrefixResolver {

    private final OntNamespaceMapper namespaceMapper;

    /** 标准前缀常量（国标固定，不从数据库加载） */
    private static final Map<String, String> STANDARD_PREFIXES = Map.of(
        "rdf", "http://www.w3.org/1999/02/22-rdf-syntax-ns#",
        "rdfs", "http://www.w3.org/2000/01/rdf-schema#",
        "xsd", "http://www.w3.org/2001/XMLSchema#",
        "owl", "http://www.w3.org/2002/07/owl#",
        "sh", "http://www.w3.org/ns/shacl#"
    );

    /**
     * 注册前缀映射到 Model
     */
    public void registerPrefixes(Model model) {
        // 1. 注册标准前缀
        STANDARD_PREFIXES.forEach((prefix, uri) ->
            model.setNsPrefix(prefix, uri));

        // 2. 注册用户命名空间（从数据库加载）
        List<OntNamespace> namespaces = namespaceMapper.selectList(null);
        for (OntNamespace ns : namespaces) {
            if (ns.getPrefix() != null && ns.getUri() != null) {
                model.setNsPrefix(ns.getPrefix(), ns.getUri());
            }
        }
    }

    /**
     * 获取所有命名空间（供导入解析器使用）
     */
    public Map<String, String> getAllPrefixes() {
        Map<String, String> prefixes = new HashMap<>(STANDARD_PREFIXES);
        List<OntNamespace> namespaces = namespaceMapper.selectList(null);
        for (OntNamespace ns : namespaces) {
            if (ns.getPrefix() != null && ns.getUri() != null) {
                prefixes.put(ns.getPrefix(), ns.getUri());
            }
        }
        return prefixes;
    }
}
```

### 3.5 谓词策略解析器

```java
/**
 * 谓词IRI策略解析器
 * <p>
 * 根据导出策略解析数据属性的谓词IRI：
 * - PREFERRED_ALIAS: 输出 preferredAlias（若非空）否则 iri
 * - STANDARD_IRI: 输出 standardIri（若非空）否则 iri
 * - INTERNAL_IRI: 始终输出 iri
 * </p>
 */
@Component
public class PredicateStrategyResolver {

    /**
     * 解析数据属性谓词IRI
     */
    public String resolveDataPropertyPredicate(OntDataProperty property,
                                                PredicateStrategy strategy) {
        switch (strategy) {
            case PREFERRED_ALIAS:
                return StringUtils.isNotBlank(property.getPreferredAlias())
                    ? property.getPreferredAlias()
                    : property.getIri();
            case STANDARD_IRI:
                return StringUtils.isNotBlank(property.getStandardIri())
                    ? property.getStandardIri()
                    : property.getIri();
            case INTERNAL_IRI:
            default:
                return property.getIri();
        }
    }

    /**
     * 解析对象属性谓词IRI
     * 对象属性无 preferredAlias/standardIri 字段，始终使用 iri
     */
    public String resolveObjectPropertyPredicate(OntObjectProperty property,
                                                  PredicateStrategy strategy) {
        return property.getIri();
    }
}
```

```java
/**
 * 导出范围解析器
 * <p>
 * 处理实例子树过滤：给定目标实体类型ID，递归收集所有子类型ID，
 * 然后加载这些类型的实例。
 * </p>
 */
@Component
@RequiredArgsConstructor
public class ExportScopeResolver {

    private final OntEntityTypeHierarchyMapper hierarchyMapper;
    private final OntEntityInstanceMapper instanceMapper;

    /**
     * 加载实例列表（按导出范围过滤）
     */
    public List<OntEntityInstance> loadInstances(Long ontologyId,
                                                  ExportScope scope,
                                                  Long targetTypeFilter) {
        if (scope == ExportScope.SCHEMA_ONLY) {
            return Collections.emptyList();
        }

        if (scope == ExportScope.INSTANCE_SUBTREE && targetTypeFilter != null) {
            // 收集目标类型及所有子类型
            Set<Long> typeIds = collectDescendants(targetTypeFilter);
            // 按类型ID列表查询实例
            return instanceMapper.selectList(
                Wrappers.<OntEntityInstance>lambdaQuery()
                    .eq(OntEntityInstance::getOntologyId, ontologyId)
                    .in(OntEntityInstance::getRdfTypeId, typeIds)
                    .eq(OntEntityInstance::getDelFlag, "0")
                    .orderByAsc(OntEntityInstance::getSortOrder));
        }

        // FULL 或 INSTANCE_ONLY：加载全部实例
        return instanceMapper.selectList(
            Wrappers.<OntEntityInstance>lambdaQuery()
                .eq(OntEntityInstance::getOntologyId, ontologyId)
                .eq(OntEntityInstance::getDelFlag, "0")
                .orderByAsc(OntEntityInstance::getSortOrder));
    }

    /**
     * 递归收集子类型ID（含自身）
     */
    private Set<Long> collectDescendants(Long rootTypeId) {
        Set<Long> result = new LinkedHashSet<>();
        Queue<Long> queue = new LinkedList<>();
        queue.add(rootTypeId);
        int depth = 0;
        while (!queue.isEmpty() && depth < 100) {
            Long current = queue.poll();
            if (result.add(current)) {
                List<OntEntityTypeHierarchy> children = hierarchyMapper.selectList(
                    Wrappers.<OntEntityTypeHierarchy>lambdaQuery()
                        .eq(OntEntityTypeHierarchy::getParentId, current));
                children.forEach(c -> queue.add(c.getChildId()));
            }
            depth++;
        }
        return result;
    }
}
```

## 5. 导出前置校验设计

### 5.1 ExportPrecheckService

```java
/**
 * 导出前置校验服务
 * <p>
 * PRD §3.3/§6.3 要求"导出前强制全量校验；Error未清零时禁用发布导出"。
 * 本服务检查最近一次全量校验报告，决定是否放行导出。
 * </p>
 */
@Slf4j
@Component
@RequiredArgsConstructor
public class ExportPrecheckService {

    private final OntValidationReportMapper reportMapper;

    /**
     * 导出前置校验
     *
     * @param ontologyId 本体工程ID
     * @param force      是否强制导出（跳过校验拦截）
     * @return 校验通过返回 null；校验未通过返回拦截原因
     */
    public ExportPrecheckResult check(Long ontologyId, boolean force) {
        if (force) {
            log.info("导出强制跳过前置校验, ontologyId={}", ontologyId);
            return ExportPrecheckResult.passed();
        }

        // 查询最近一次全量校验报告
        OntValidationReport latestReport = reportMapper.selectOne(
            Wrappers.<OntValidationReport>lambdaQuery()
                .eq(OntValidationReport::getOntologyId, ontologyId)
                .eq(OntValidationReport::getScope, "FULL")
                .eq(OntValidationReport::getStatus, "COMPLETED")
                .orderByDesc(OntValidationReport::getTriggeredAt)
                .last("LIMIT 1"));

        if (latestReport == null) {
            return ExportPrecheckResult.blocked(
                "尚未执行全量校验，请先在校验中心执行全量校验后再导出",
                null);
        }

        if (!Boolean.TRUE.toString().equals(latestReport.getConforms())
            && latestReport.getViolationCount() != null
            && latestReport.getViolationCount() > 0) {
            return ExportPrecheckResult.blocked(
                "最近一次全量校验存在 " + latestReport.getViolationCount()
                    + " 条违规，请修复后导出或使用强制导出",
                latestReport.getId());
        }

        return ExportPrecheckResult.passed();
    }
}
```

```java
/**
 * 导出前置校验结果
 */
@Data
@Builder
public class ExportPrecheckResult {
    private boolean passed;
    private String blockedReason;
    private Long validationReportId;
```

## 6. 导入解析设计

### 6.1 导入流程（两阶段）

```
阶段1：预检（POST /serialization/import/preview）
  ├── 接收上传的 RDF 文件（Turtle/JSON-LD/RDF/XML/N-Triples）
  ├── 使用 Jena RDFParser 解析为 Model
  ├── 遍历 Model 三元组，分类为：
  │   ├── Schema 三元组（owl:Class/owl:DatatypeProperty/owl:ObjectProperty 声明）→ 跳过
  │   ├── 实例类型三元组（rdf:type → 非OWL内置类型）→ 映射到 ont_entity_instance
  │   ├── 数据属性值三元组（谓词→字面量）→ 映射到 ont_instance_data_value
  │   └── 对象属性断言三元组（谓词→资源）→ 映射到 ont_instance_object_relation
  ├── 执行冲突检测：
  │   ├── IRI 重复（数据库已存在同IRI实例）→ 标记 SKIP/MERGE/OVERWRITE
  │   ├── rdf:type 对应的实体类型不存在 → 标记 ERROR
  │   ├── 谓词IRI 对应的数据属性/对象属性不存在 → 标记 WARNING（作为自定义属性）
  │   └── 字面量类型不匹配 → 标记 WARNING
  └── 返回预检报告（不写入数据库）

阶段2：确认写入（POST /serialization/import/confirm）
  ├── 接收预检ID + 用户确认的映射方案
  ├── 按 IRIMergeMode 处理冲突：
  │   ├── SKIP：跳过已存在的实例
  │   ├── MERGE：保留已有实例，追加新数据值和关系
  │   └── OVERWRITE：删除已有实例的全部数据值和关系，重新写入
  ├── 写入 ont_entity_instance / ont_instance_data_value / ont_instance_object_relation
  └── 返回导入结果（成功数、跳过数、失败数）
```

### 6.2 RdfFileParser

```java
/**
 * RDF 文件解析器
 * <p>
 * 使用 Jena RDFParser 解析上传的 RDF 文件为 Model。
 * 支持自动格式检测或指定格式。
 * </p>
 */
@Component
@RequiredArgsConstructor
public class RdfFileParser {

    private final NamespacePrefixResolver prefixResolver;

    /**
     * 解析 RDF 文件内容为 Model
     *
     * @param content  RDF 文件内容
     * @param format   指定格式（null 则自动检测）
     * @return 解析后的 Jena Model（含前缀映射）
     */
    public Model parse(String content, RdfFormat format) {
        Model model = ModelFactory.createDefaultModel();

        // 注册已知前缀（帮助解析器解析无前缀声明的缩写IRI）
        prefixResolver.registerPrefixes(model);

        RDFParser parser = RDFParser.create();
        if (format != null) {
            parser.lang(parseLang(format));
        } else {
            parser.lang(RDFLanguages.RDFTURTLE);  // 默认尝试 Turtle
        }

        parser.source(new StringReader(content))
            .parse(model);

        return model;
    }

    private Lang parseLang(RdfFormat format) {
        switch (format) {
            case TURTLE: return Lang.TURTLE;
            case JSON_LD: return Lang.JSONLD;
            case RDF_XML: return Lang.RDFXML;
            case N_TRIPLES: return Lang.NTRIPLES;
            default: return Lang.TURTLE;
        }
    }
}
```

### 6.3 InstanceImportMapper

```java
/**
 * 实例导入映射器
 * <p>
 * 将解析后的 Jena Model 映射为内部实例数据结构。
 * 仅处理实例数据三元组，Schema 声明三元组被跳过。
 * </p>
 */
@Slf4j
@Component
@RequiredArgsConstructor
public class InstanceImportMapper {

    private final OntEntityTypeMapper entityTypeMapper;
    private final OntDataPropertyMapper dataPropertyMapper;
    private final OntObjectPropertyMapper objectPropertyMapper;
    private final OntEntityInstanceMapper instanceMapper;
    private final OntUnitMapper unitMapper;
    private final NamespacePrefixResolver prefixResolver;

    // OWL/RDFS 标准类型IRI集合，用于过滤Schema三元组
    private static final Set<String> SCHEMA_TYPES = Set.of(
        OWL.Class.getURI(),
        OWL.DatatypeProperty.getURI(),
        OWL.ObjectProperty.getURI(),
        OWL.FunctionalProperty.getURI(),
        OWL.InverseFunctionalProperty.getURI(),
        OWL.TransitiveProperty.getURI(),
        OWL.SymmetricProperty.getURI(),
        OWL.AnnotationProperty.getURI(),
        OWL.Ontology.getURI(),
        SHACL.NodeShape.getURI(),
        SHACL.PropertyShape.getURI()
    );

    /**
     * 将 Model 映射为导入预检结果
     *
     * @param model      解析后的 Model
     * @param ontologyId 目标本体工程ID
     * @return 预检结果（不写入数据库）
     */
    public ImportPreviewResult mapToPreview(Model model, Long ontologyId) {
        ImportPreviewResult preview = new ImportPreviewResult();
        preview.setOntologyId(ontologyId);

        // 1. 构建IRI→实体类型映射（用于解析 rdf:type）
        Map<String, OntEntityType> typeIriMap = buildEntityTypeIriMap(ontologyId);

        // 2. 构建谓词IRI→数据属性/对象属性映射
        Map<String, OntDataProperty> dataPropIriMap = buildDataPropertyIriMap(ontologyId);
        Map<String, OntObjectProperty> objPropIriMap = buildObjectPropertyIriMap(ontologyId);

        // 3. 构建已有实例IRI集合（用于冲突检测）
        Set<String> existingIris = buildExistingInstanceIris(ontologyId);

        // 4. 遍历 Model 三元组
        Map<String, ImportInstance> instanceMap = new LinkedHashMap<>();

        for (StmtIterator it = model.listStatements(); it.hasNext(); ) {
            Statement stmt = it.next();
            String subject = stmt.getSubject().getURI();
            Property predicate = stmt.getPredicate();
            RDFNode object = stmt.getObject();

            // 跳过 Schema 声明三元组
            if (isSchemaStatement(stmt)) {
                preview.incrementSchemaSkipped();
                continue;
            }

            // rdf:type 三元组 → 实例声明
            if (predicate.equals(RDF.type)) {
                String typeUri = object.asResource().getURI();
                if (SCHEMA_TYPES.contains(typeUri)) {
                    // 这是 Schema 声明，跳过
                    preview.incrementSchemaSkipped();
                    continue;
                }
                ImportInstance instance = instanceMap.computeIfAbsent(subject,
                    iri -> new ImportInstance(iri));
                OntEntityType type = typeIriMap.get(typeUri);
                if (type != null) {
                    instance.setRdfTypeId(type.getId());
                    instance.setRdfTypeIri(typeUri);
                } else {
                    preview.addError(subject, "rdf:type " + typeUri
                        + " 对应的实体类型不存在");
                }
                continue;
            }

            // rdfs:label 三元组 → 实例标签
            if (predicate.equals(RDFS.label)) {
                ImportInstance instance = instanceMap.computeIfAbsent(subject,
                    iri -> new ImportInstance(iri));
                instance.setLabel(object.asLiteral().getString());
                continue;
            }

            // 数据属性值三元组（object 是 Literal）
            if (object.isLiteral()) {
                OntDataProperty dp = dataPropIriMap.get(predicate.getURI());
                ImportInstance instance = instanceMap.computeIfAbsent(subject,
                    iri -> new ImportInstance(iri));
                ImportDataValue dv = new ImportDataValue();
                dv.setPredicateIri(predicate.getURI());
                dv.setLiteralValue(object.asLiteral().getString());
                dv.setLiteralType(inferLiteralType(object.asLiteral(), dp));
                if (dp != null) {
                    dv.setDataPropertyId(dp.getId());
                    // UNIT_REF 类型：尝试按符号解析单位
                    if ("UNIT_REF".equals(dp.getValueMode())) {
                        resolveUnitBySymbol(dv, object.asLiteral().getString(), ontologyId);
                    }
                } else {
                    preview.addWarning(subject, "谓词 " + predicate.getURI()
                        + " 未匹配到已知数据属性，将作为自定义属性导入");
                }
                instance.addDataValue(dv);
                continue;
            }

            // 对象属性断言三元组（object 是 Resource）
            if (object.isResource()) {
                OntObjectProperty op = objPropIriMap.get(predicate.getURI());
                ImportInstance instance = instanceMap.computeIfAbsent(subject,
                    iri -> new ImportInstance(iri));
                ImportObjectRelation rel = new ImportObjectRelation();
                rel.setPredicateIri(predicate.getURI());
                rel.setObjectIri(object.asResource().getURI());
                if (op != null) {
                    rel.setObjectPropertyId(op.getId());
                } else {
                    preview.addWarning(subject, "谓词 " + predicate.getURI()
                        + " 未匹配到已知对象属性，将作为自定义关系导入");
                }
                instance.addObjectRelation(rel);
                continue;
            }
        }

        // 5. 冲突检测
        for (ImportInstance instance : instanceMap.values()) {
            if (existingIris.contains(instance.getIri())) {
                instance.setConflictType("IRI_EXISTS");
                preview.incrementConflictCount();
            }
        }

        preview.setInstances(new ArrayList<>(instanceMap.values()));
        return preview;
    }

    /**
     * 判断是否为 Schema 声明三元组
     */
    private boolean isSchemaStatement(Statement stmt) {
        Property predicate = stmt.getPredicate();
        // rdfs:subClassOf, rdfs:domain, rdfs:range, owl:disjointWith,
        // owl:equivalentClass, owl:inverseOf 等都是 Schema 声明
        return predicate.equals(RDFS.subClassOf)
            || predicate.equals(RDFS.domain)
            || predicate.equals(RDFS.range)
            || predicate.equals(OWL.disjointWith)
            || predicate.equals(OWL.equivalentClass)
            || predicate.equals(OWL.inverseOf);
    }
}
```

### 8.3 导出编排流程

```
exportOntology(ExportRequest)
  │
  ├── 1. 参数校验
  │     - ontologyId 为空则默认 CORE_ONTOLOGY_ID
  │     - format 为空则默认 TURTLE
  │     - scope 为空则默认 FULL
  │     - predicateStrategy 为空则默认 PREFERRED_ALIAS
  │     - scope=INSTANCE_SUBTREE 时 targetTypeId 必填
  │
  ├── 2. 导出前置校验
  │     precheckResult = exportPrecheckService.check(ontologyId, force)
  │     if (!precheckResult.isPassed()):
  │       return ExportResultVO with precheck blocked
  │
  ├── 3. 组装 Model
  │     model = ontologyModelExporter.buildCompleteModel(
  │       ontologyId, scope, predicateStrategy, targetTypeId)
  │
  ├── 4. 序列化为字符串
  │     serializer = rdfSerializerRegistry.getSerializer(format)
  │     content = serializer.serialize(model)
  │
  ├── 5. 记录审计日志
  │     serializationLogService.logExport(ontologyId, format, scope,
  │       model.size(), content.length(), precheckResult, currentUser)
  │
  └── 6. 返回结果
        ExportResultVO {
          format, content, tripleCount=model.size(),
          scope, predicateStrategy, precheck, logId
        }
```

### 8.4 导入编排流程

```
importPreview(file, ontologyId, format)
  │
  ├── 1. 参数校验
  │     - file 非空，大小 ≤ 10MB
  │     - ontologyId 为空则默认 CORE_ONTOLOGY_ID
  │
  ├── 2. 解析 RDF 文件
  │     content = new String(file.getBytes(), UTF-8)
  │     model = rdfFileParser.parse(content, format)
  │
  ├── 3. 映射为预检结果
  │     preview = instanceImportMapper.mapToPreview(model, ontologyId)
  │
  ├── 4. 缓存预检结果（30分钟TTL）
  │     previewId = importPreviewCache.put(preview)
  │
  └── 5. 返回预检报告
        ImportPreviewVO { previewId, summary, instances, conflicts, errors, warnings }

importConfirm(request)
  │
  ├── 1. 从缓存获取预检结果
  │     preview = importPreviewCache.get(request.getPreviewId())
  │     if (preview == null):
  │       throw "预检结果已过期，请重新上传"
  │
  ├── 2. 按合并模式处理冲突
  │     for each instance in preview.instances:
  │       if (instance.conflictType == "IRI_EXISTS"):
  │         switch (iriMergeMode):
  │           case SKIP: 跳过该实例
  │           case MERGE: 保留已有，追加新数据
  │           case OVERWRITE: 删除已有数据值和关系，重新写入
  │
  ├── 3. 写入数据库（事务）
  │     @Transactional:
  │       for each instance (非SKIP):
  │         if (MERGE or new): INSERT ont_entity_instance
  │         if (OVERWRITE): DELETE old data values + relations, then INSERT
  │         INSERT ont_instance_data_value (batch)
  │         INSERT ont_instance_object_relation (batch)
  │
  ├── 4. 记录审计日志
  │     serializationLogService.logImport(ontologyId, format,
  │       importedCount, skippedCount, failedCount, currentUser)
  │
  └── 5. 返回导入结果
        ImportResultVO { totalInstances, importedCount, skippedCount,
          failedCount, dataValueCount, objectRelationCount, durationMs, logId }
```

```java
/**
 * 序列化与交换 REST API
 */
@RestController
@RequestMapping("/ontology/serialization")
@RequiredArgsConstructor
@Tag(name = "本体序列化与交换")
public class OntSerializationController {

    private final SerializationService serializationService;

    /**
     * 导出本体（返回文本内容或文件下载流）
     */
    @GetMapping("/export")
    @SneakyThrows
    @Operation(summary = "导出本体", description = "支持Turtle/JSON-LD/RDF-XML/N-Triples格式")
    public void export(
            @ParameterObject ExportRequest request,
            HttpServletResponse response) {

        if (Boolean.TRUE.equals(request.getDownload())) {
            // 文件下载模式
            serializationService.exportToFile(request, response);
        } else {
            // 文本内容模式
            ExportResultVO result = serializationService.exportOntology(request);
            response.setContentType("application/json;charset=UTF-8");
            response.getWriter().write(JSONUtil.toJsonStr(R.ok(result)));
        }
    }

    /**
     * 预览导出内容
     */
    @GetMapping("/preview")
    @Operation(summary = "预览导出内容")
    public R<ExportPreviewVO> preview(@ParameterObject ExportRequest request) {
        return R.ok(serializationService.previewExport(request));
    }

    /**
     * 获取支持的格式列表
     */
    @GetMapping("/formats")
    @Operation(summary = "获取支持的RDF格式")
    public R<List<Map<String, String>>> formats() {
        return R.ok(Arrays.stream(RdfFormat.values())
            .map(f -> Map.of("value", f.name(), "label", f.getDisplayName(),
                "extension", f.getFileExtension()))
            .collect(Collectors.toList()));
    }

    /**
     * 获取支持的导出范围
     */
    @GetMapping("/scopes")
    @Operation(summary = "获取支持的导出范围")
    public R<List<Map<String, String>>> scopes() {
        return R.ok(Arrays.stream(ExportScope.values())
            .map(s -> Map.of("value", s.name(), "label", s.getDescription()))
            .collect(Collectors.toList()));
    }

    /**
     * 导入预检
     */
    @PostMapping("/import/preview")
    @Operation(summary = "上传RDF文件并预检映射")
    public R<ImportPreviewVO> importPreview(
            @RequestPart("file") MultipartFile file,
            @RequestParam(required = false) Long ontologyId,
            @RequestParam(required = false) RdfFormat format) {
        return R.ok(serializationService.importPreview(file, ontologyId, format));
    }

    /**
     * 导入确认
     */
    @PostMapping("/import/confirm")
    @Operation(summary = "确认导入并写入数据库")
    public R<ImportResultVO> importConfirm(@Valid @RequestBody ImportConfirmRequest request) {
        return R.ok(serializationService.importConfirm(request));
    }

    /**
     * 审计日志查询
     */
    @GetMapping("/logs")
    @Operation(summary = "导出/导入审计日志")
    public R<IPage<SerializationLogVO>> logs(@ParameterObject SerializationLogQuery query) {
        return R.ok(serializationService.queryLogs(query));
    }
}
```

### 11.3 验收测试断言

```java
/**
 * 附录D导出验证测试
 * <p>
 * PRD §5.4 验收标准：导出Turtle与附录D语义等价。
 * 本测试通过断言关键三元组存在性来验证等价性。
 * </p>
 */
@SpringBootTest
class AppendixDExportVerificationTest {

    @Autowired
    private OntologyModelExporter modelExporter;
    @Autowired
    private RdfSerializerRegistry serializerRegistry;

    private Model exportedModel;

    @BeforeEach
    void setup() {
        exportedModel = modelExporter.buildCompleteModel(
            935001L,
            ExportScope.FULL,
            PredicateStrategy.PREFERRED_ALIAS,
            null);
    }

    @Test
    void shouldExportCompleteSchema() {
        // 验证类声明
        Resource standard = exportedModel.getResource(
            "http://example.org/standard-ontology#Standard");
        assertThat(exportedModel.contains(standard, RDF.type, OWL.Class)).isTrue();

        // 验证继承关系
        Resource termStandard = exportedModel.getResource(
            "http://example.org/standard-ontology#TermStandard");
        assertThat(exportedModel.contains(termStandard, RDFS.subClassOf, standard)).isTrue();

        // 验证不相交声明
        Resource normativeElement = exportedModel.getResource(
            "http://example.org/standard-ontology#NormativeElement");
        Resource informativeElement = exportedModel.getResource(
            "http://example.org/standard-ontology#InformativeElement");
        assertThat(exportedModel.contains(normativeElement, OWL.disjointWith, informativeElement))
            .isTrue();
    }

    @Test
    void shouldExportDataPropertyDeclarations() {
        // 验证数据属性声明
        Resource measurementUnit = exportedModel.getResource(
            "http://example.org/standard-ontology#measurementUnit");
        assertThat(exportedModel.contains(measurementUnit, RDF.type, OWL.DatatypeProperty))
            .isTrue();

        // 验证定义域
        Resource constraint = exportedModel.getResource(
            "http://example.org/standard-ontology#Constraint");
        assertThat(exportedModel.contains(measurementUnit, RDFS.domain, constraint))
            .isTrue();
    }

    @Test
    void shouldExportObjectPropertyDeclarations() {
        // 验证对象属性声明
        Resource hasClause = exportedModel.getResource(
            "http://example.org/standard-ontology#hasClause");
        assertThat(exportedModel.contains(hasClause, RDF.type, OWL.ObjectProperty))
            .isTrue();

        // 验证功能性属性
        Resource issuedBy = exportedModel.getResource(
            "http://example.org/standard-ontology#issuedBy");
        assertThat(exportedModel.contains(issuedBy, RDF.type, OWL.FunctionalProperty))
            .isTrue();
    }

    @Test
    void shouldExportAppendixDStep1_StandardEntity() {
        Resource gb31486 = exportedModel.getResource(
            "http://example.org/standard/GB-T-31486-2024/GB-T_31486-2024");

        // rdf:type
        Resource standard = exportedModel.getResource(
            "http://example.org/standard-ontology#Standard");
        assertThat(exportedModel.contains(gb31486, RDF.type, standard)).isTrue();

        // 数据属性值
        Property standardNumber = exportedModel.getProperty(
            "http://example.org/standard-ontology#standardNumber");
        assertThat(exportedModel.contains(gb31486, standardNumber, "GB/T 31486—2024"))
            .isTrue();

        // 日期格式验证（YYYY-MM-DD）
        Property issuedDate = exportedModel.getProperty(
            "http://example.org/standard-ontology#issuedDate");
        StmtIterator it = exportedModel.listStatements(gb31486, issuedDate, (RDFNode) null);
        assertThat(it.hasNext()).isTrue();
        Literal dateLiteral = it.next().getLiteral();
        assertThat(dateLiteral.getDatatype()).isEqualTo(XSDDatatype.XSDdate);
        assertThat(dateLiteral.getString()).isEqualTo("2024-09-29");
    }

    @Test
    void shouldExportAppendixDStep5_ConstraintWithMeasurementUnit() {
        Resource constraint1 = exportedModel.getResource(
            "http://example.org/standard/GB-T-31486-2024/Capacity_Constraint_1");

        // measurementUnit 值为 "%"（UNIT_REF序列化为符号字面量）
        Property measurementUnit = exportedModel.getProperty(
            "http://example.org/standard-ontology#measurementUnit");
        assertThat(exportedModel.contains(constraint1, measurementUnit, "%"))
            .isTrue();

        // maxValue 为数值型
        Property maxValue = exportedModel.getProperty(
            "http://example.org/standard-ontology#maxValue");
        StmtIterator it = exportedModel.listStatements(constraint1, maxValue, (RDFNode) null);
        assertThat(it.hasNext()).isTrue();
        Literal valueLiteral = it.next().getLiteral();
        assertThat(valueLiteral.getDatatype()).isEqualTo(XSDDatatype.XSDdecimal);
    }

    @Test
    void shouldExportAppendixDStep9_StandardizesRelation() {
        Resource gb31486 = exportedModel.getResource(
            "http://example.org/standard/GB-T-31486-2024/GB-T_31486-2024");
        Resource batteryObj = exportedModel.getResource(
            "http://example.org/standard/GB-T-31486-2024/BatteryStandardizationObject");
        Property standardizes = exportedModel.getProperty(
            "http://example.org/standard-ontology#standardizes");

        assertThat(exportedModel.contains(gb31486, standardizes, batteryObj))
            .isTrue();
    }

    @Test
    void shouldSerializeToValidTurtle() {
        RdfSerializer turtleSerializer = serializerRegistry.getSerializer(RdfFormat.TURTLE);
        String turtle = turtleSerializer.serialize(exportedModel);

        // 包含 @prefix 声明
        assertThat(turtle).contains("@prefix");
        assertThat(turtle).contains("@prefix : <http://example.org/standard-ontology#>");

        // 可被重新解析为 Model（格式合法）
        Model reparsed = ModelFactory.createDefaultModel();
        reparsed.read(new StringReader(turtle), null, "TURTLE");
        assertThat(reparsed.size()).isGreaterThan(0);
    }

    @Test
    void shouldExportWithPreferredAliasStrategy() {
        // 使用 PREFERRED_ALIAS 策略，measurementUnit 应使用别名而非 standardIri(unit)
        Property measurementUnit = exportedModel.getProperty(
            "http://example.org/standard-ontology#measurementUnit");
        Property unit = exportedModel.getProperty(
            "http://example.org/standard-ontology#unit");

        // PREFERRED_ALIAS 下应有 measurementUnit 谓词
        assertThat(exportedModel.contains(null, measurementUnit, (RDFNode) null)).isTrue();
        // 不应有 unit 谓词（除非另有声明）
        // 注意：这取决于 preferredAlias 字段是否正确预置
    }

    @Test
    void shouldExportAll29AppendixDInstances() {
        // 统计 rdf:type 为核心实体类型的实例数
        Resource standard = exportedModel.getResource(
            "http://example.org/standard-ontology#Standard");
        long standardCount = exportedModel.listStatements(null, RDF.type, standard).toList().size();
        assertThat(standardCount).isEqualTo(1); // GB-T_31486-2024

        // 总实例数（非Schema声明的 rdf:type 三元组）
        long instanceTypeCount = exportedModel.listStatements(null, RDF.type, (RDFNode) null)
            .filterKeep(stmt -> !stmt.getObject().isResource()
                || !stmt.getObject().asResource().getURI().startsWith(
                    "http://www.w3.org/"))
            .toList().size();
        assertThat(instanceTypeCount).isGreaterThanOrEqualTo(29);
    }
}
```

| SPARQL查询端点 | 暴露SPARQL查询接口供外部系统查询 | 中（可视化模块或后续扩展） |
| Triplestore双写 | 导出Model同步写入Jena TDB/GraphDB | 低（本期不引入Triplestore） |
| 导入后自动校验 | 导入写入后自动触发SHACL校验 | 中（可配置开关） |

## 14. 验收标准

1. **导出格式完整性**：支持 Turtle、JSON-LD、RDF/XML、N-Triples 四种格式导出，每种格式均可被 Jena 重新解析为合法 Model。

2. **Schema层导出完整性**：导出 Model 包含全部 86 个实体类型的 `owl:Class` 声明、72 条 `rdfs:subClassOf` 继承关系、1 条 `owl:disjointWith` 不相交声明、47 个数据属性的 `owl:DatatypeProperty` 声明（含 `rdfs:domain`/`rdfs:range`）、34 个对象属性的 `owl:ObjectProperty` 声明（含语义标记）。

3. **Data层导出完整性**：导出 Model 包含全部 29 个附录D实例的 `rdf:type` 断言、83 条数据属性值三元组、39 条对象属性断言三元组。

4. **前缀映射正确性**：导出的 Turtle 文本包含 `@prefix` 声明，覆盖全部 6 个用户命名空间（std/rdf/rdfs/owl/xsd/gbt31486）+ 标准前缀（sh）。

5. **日期格式转换**：日期型数据属性值导出为 `xsd:date` 词法形式（`YYYY-MM-DD`），平台内部存储的 `YYYYMMDD` 格式被正确转换。

6. **UNIT_REF序列化**：`measurementUnit` 等单位引用属性值序列化为单位符号字面量（如 `"%"`、`"V"`），从 `literal_symbol` 优先读取，回退查 `ont_unit.unit_symbol`。

7. **谓词策略可切换**：`PREFERRED_ALIAS` 策略输出 `measurementUnit`（附录D兼容），`STANDARD_IRI` 策略输出 `unit`（国标严格口径），`INTERNAL_IRI` 策略输出内部 `iri`。

8. **导出前置校验拦截**：最近全量校验报告 `conforms=false` 时拦截导出并返回违规数+报告链接；`force=true` + `ontology_export_force` 权限可跳过拦截。

9. **导出范围控制**：`FULL` 导出Schema+Data，`SCHEMA_ONLY` 仅导出Schema，`INSTANCE_ONLY` 仅导出Data，`INSTANCE_SUBTREE` 按实体类型子树过滤实例。

10. **导入文件解析**：支持上传 Turtle/JSON-LD/RDF/XML/N-Triples 格式文件，解析为 Model 并映射为实例数据结构。

11. **导入两阶段流程**：预检阶段不写入数据库，生成映射预览（实例数/冲突/错误/警告）；确认阶段按合并模式写入数据库。

12. **导入冲突处理**：IRI已存在的实例支持 SKIP（跳过）/MERGE（追加）/OVERWRITE（覆盖）三种合并模式。

13. **导入Schema跳过**：导入时自动识别并跳过 Schema 声明三元组（`owl:Class`/`owl:DatatypeProperty`/`owl:ObjectProperty` 声明及 `rdfs:subClassOf`/`rdfs:domain`/`rdfs:range` 等）。

14. **审计日志留痕**：每次导出/导入操作写入 `ont_serialization_log` 表，记录操作类型、格式、范围、三元组数、文件大小、耗时、操作人、时间。

15. **附录D导出语义等价**：`AppendixDExportVerificationTest` 全部断言通过，导出Turtle包含附录D 9步配置的全部关键三元组（标准实体定义、层次结构、对象、特性、约束逻辑含measurementUnit、行动、条款关联、外部引用、标准化对象）。

16. **菜单权限**：V12 迁移脚本写入"导入导出"菜单（900900）及 4 个按钮权限（900901-900904），管理员角色已授权。

17. **前端页面完整**：导出面板（格式/范围/策略选择、前置校验状态、预览、下载）、导入面板（上传、预检报告、冲突处理、确认写入）、审计日志面板三个Tab全部可用。

18. **实例页面集成**：实例管理页面顶部增加"导出当前类型"快捷按钮，调用 `INSTANCE_SUBTREE` 范围导出。
