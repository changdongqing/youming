# 单体版开发服务器本机配置要求

> 适用对象：使用 `pig-boot` 单体模块进行本机开发调试的开发者。
> IDE：Visual Studio Code（不适用 IntelliJ IDEA）。
> 后端目录：`server/`，前端目录：`web/`。

## 一、架构说明

单体版通过 `pig-boot` 模块运行，**不依赖 Nacos、不依赖 Spring Cloud Gateway、不依赖 Sentinel**：

- 关闭 `spring.cloud.discovery`、`nacos.config/discovery`、`sentinel`。
- 直连 PostgreSQL（业务库 `youmingdb`）与 Redis。
- 服务端口 `9999`，统一上下文路径 `/admin`（即所有接口前缀为 `http://127.0.0.1:9999/admin`）。
- 激活 Profile：`dev`（`application-dev.yml`）。

> **数据库说明**：youming 已从上游 pig 的 MySQL 迁移至 **PostgreSQL**（业务库 + Nacos 元数据库全部去 MySQL）。库结构由 **Flyway** 统一管理，应用启动时自动迁移到最新版本，无需手工导入 SQL。迁移设计与核验记录见 `docs/dbversion/`。

单体版仅需启动 1 个后端进程 + 1 个前端进程，适合快速本地调试与功能验证。

## 二、本机配置要求

### 2.1 软件环境

| 软件 | 版本要求 | 说明 |
|------|---------|------|
| JDK | 17（必须） | 项目 `maven.compiler.source/target=17`；推荐 Temurin / Zulu 17 |
| Maven | 3.8+ | 用于编译 `pig-boot`；需激活 `boot` profile |
| Node.js | 18.x+（推荐 20 LTS） | 前端构建；Vite 8 对 Node 版本有要求 |
| npm | 随 Node 自带，或使用 pnpm/yarn | — |
| PostgreSQL | 14+（推荐 18.x） | 业务库 `youmingdb`；库结构由 Flyway 自动初始化，无需手工建表 |
| Redis | 6.x / 7.x / 8.x | 单体版默认使用 db `5` |
| Git | 2.20+ | — |
| Docker（可选） | — | 仅当用容器跑 PostgreSQL/Redis 时需要 |

### 2.2 VSCode 必装扩展

| 扩展 | 用途 |
|------|------|
| **Extension Pack for Java**（vscjava） | Java 语言支持、调试、Maven 集成（含 Java Debugger + Maven for Java） |
| **Spring Boot Extension Pack** | Spring 配置提示、application.yml 智能补全 |
| **Vue - Official**（Volar） | Vue 3 SFC 支持 |
| **ESLint** / **Prettier** | 前端代码规范 |
| **TypeScript Vue Plugin** | TS + Vue 类型提示 |

> Java 扩展包会自动拉取 Red Hat Java 语言服务器；首次打开 `server/` 会下载依赖，请保持网络通畅。

### 2.3 硬件建议

- CPU 4 核及以上
- 内存 8 GB 及以上（JVM + Node + PostgreSQL/Redis）
- 磁盘 10 GB 可用空间（Maven 依赖、npm 依赖）

## 三、数据库与缓存准备

### 3.1 初始化 PostgreSQL

单体版业务库为 `youmingdb`，**库结构由 Flyway 在应用启动时自动迁移**（基线脚本 V1/V2/V3 见 `server/pig-common/pig-common-data/src/main/resources/db/migration/`），开发者只需创建空库即可。

1. 创建空数据库（本机无 psql CLI 时，通过 docker exec 操作；容器名/凭证按本机实际，可参考根 `AGENTS.md`）：

   ```bash
   docker exec -e PGPASSWORD=<密码> <pg容器名> psql -U <用户名> -d postgres -c "CREATE DATABASE youmingdb;"
   ```

   > 本机环境（1Panel 管理）参考凭证：容器 `1Panel-postgresql-ANBv`，用户 `user_PAmcy2` / 密码 `password_bkQ4JT`，端口 5432。详见根 `AGENTS.md`。

2. 无需手工建表——`pig-boot` 首次启动时，Flyway 会自动执行 V1（38 业务表结构）→ V2（种子数据）→ V3（Quartz 11 表），并在 `flyway_schema_history` 表记录迁移历史。

   > 若需手工预导（如排查 DDL），可执行 `server/db/postgresql/` 下的脚本：`V1__init_schema.sql` → `quartz/tables_postgres.sql` → `V1__init_data.sql`。

> ⚠️ 上游 pig 的 `server/db/pig.sql`、`pig_config.sql` 为 **MySQL 脚本，已弃用**（仅作迁移源参考）。开发测试一律用 PostgreSQL，不要导入这两个文件。

### 3.2 启动 Redis

```bash
# 本机直接启动
redis-server --daemonize yes
# 或 docker
docker run -d --name pig-redis -p 6379:6379 redis:7
```

### 3.3 （可选）一键拉起 PostgreSQL + Redis

`server/docker-compose-boot.yml` 已提供 Redis 容器与（注释状态的）PostgreSQL 服务定义。本机调试通常直接复用 1Panel 已运行的 PostgreSQL/Redis 容器；如需纯净容器环境，可参考 `server/db/postgresql/Dockerfile` 构建带初始化脚本的 PG 镜像。

## 四、后端配置与启动（VSCode）

### 4.1 编译 pig-boot

单体模块需激活根 pom 的 `boot` profile（该 profile 只包含 `pig-boot` 一个模块）：

```bash
cd server
mvn clean install -Pboot -DskipTests
```

> 首次编译会下载大量依赖，耗时较长。若网络不佳，建议配置阿里云 Maven 镜像（`~/.m2/settings.xml`）。

### 4.2 确认本机数据源配置

`server/pig-boot/src/main/resources/application-dev.yml` 默认连接 PostgreSQL 与 Redis，并通过 `${PG_*}` / `${REDIS_*}` 占位符支持环境变量覆盖：

```yaml
spring:
  data:
    redis:
      host: ${REDIS_HOST:127.0.0.1}
      database: 5
      password: ${REDIS_PASSWORD:redis_6QX4h2}
  datasource:
    druid:
      driver-class-name: org.postgresql.Driver
      username: ${PG_USER:user_PAmcy2}
      password: ${PG_PASSWORD:password_bkQ4JT}
      url: jdbc:postgresql://${PG_HOST:127.0.0.1}:${PG_PORT:5432}/${PG_DB:youmingdb}
```

> 默认值对应本机 1Panel 环境的 PostgreSQL/Redis 容器（凭证见根 `AGENTS.md`）。若本机凭证不同，**优先用环境变量覆盖**（不改源文件）：
>
> ```bash
> export PG_HOST=127.0.0.1 PG_PORT=5432 PG_DB=youmingdb PG_USER=<你的用户> PG_PASSWORD=<你的密码>
> export REDIS_HOST=127.0.0.1 REDIS_PASSWORD=<你的redis密码>
> ```
>
> 也可新增 `application-local.yml` 并以 `--spring.profiles.active=local` 启动。

### 4.3 VSCode 启动配置

在仓库根目录创建 `.vscode/launch.json`：

```json
{
  "version": "0.2.0",
  "configurations": [
    {
      "type": "java",
      "name": "PigBoot (单体)",
      "request": "launch",
      "mainClass": "com.pig4cloud.pig.PigBootApplication",
      "projectName": "pig-boot",
      "cwd": "${workspaceFolder}/server",
      "args": "--spring.profiles.active=dev",
      "vmArgs": "-Xms512m -Xmx1024m"
    }
  ]
}
```

启动步骤：

1. VSCode 打开仓库根目录 `youming/`。
2. 确认 Maven 扩展已识别 `server/` 为多模块项目（左下角状态栏 / Maven 面板可见 `pig-boot`）。
3. 按 `F5`（或运行配置下拉选 `PigBoot (单体)`），Java 调试器启动 `PigBootApplication`。
4. 控制台出现 `Started PigBootApplication ... in N seconds` 即启动成功。
5. 访问 `http://127.0.0.1:9999/admin/actuator/health` 验证（需放开 actuator，单体默认 `management.endpoints.access.default: none`，可用接口测试代替）。

> 断点调试：在任意 Java 方法行号左侧点击设置断点，`F5` 启动后命中即暂停，支持变量查看、表达式求值。

## 五、前端配置与启动（VSCode）

### 5.1 切换为单体模式

编辑 `web/.env`，将微服务标志改为 `false`：

```bash
# 是否是微服务架构（重要）—— 单体版必须改为 false
VITE_IS_MICRO=false
```

> 该标志决定前端请求路径前缀：
> - `true`（微服务）：验证码等走 `/auth/**`（经 gateway 路由到 pig-auth）。
> - `false`（单体）：走 `/admin/**`（直连 pig-boot 的 context-path）。

### 5.2 确认后端代理地址

`web/.env.development` 中：

```
VITE_PORT=8888
VITE_ADMIN_PROXY_PATH=http://127.0.0.1:9999
```

与单体后端端口 9999 一致，无需修改。

### 5.3 安装依赖并启动

```bash
cd web
npm install        # 或 pnpm install / yarn
npm run dev        # 即 vite --force，开发服务器
```

启动步骤（VSCode）：

1. VSCode 打开 `web/`（或在根目录通过终端 `cd web`）。
2. 在集成终端（`` Ctrl+` ``）执行上述 `npm install` 与 `npm run dev`。
3. Vite 启动后默认自动打开浏览器 `http://127.0.0.1:8888`。
4. 前端请求经 Vite 代理转发至 `http://127.0.0.1:9999`（单体后端）。

> 前端断点调试：VSCode 安装 Volar 后，可在 `.vue`/`.ts` 中使用浏览器 DevTools 调试；也可用 `Launch Chrome` 配置配合 sourcemap。

## 六、启动顺序总结

单体版启动顺序：

1. 启动 PostgreSQL、Redis（本机或容器），创建空库 `youmingdb`。
2. `mvn clean install -Pboot -DskipTests`（首次或依赖变更时）。
3. VSCode `F5` 启动 `PigBootApplication`——Flyway 首次启动会自动建表 + 导入种子数据，等待 9999 端口就绪。
4. `web/` 下 `npm install && npm run dev`，打开 `http://127.0.0.1:8888`。

## 八、常见问题

| 现象 | 原因 / 处理 |
|------|------------|
| 启动报 Flyway `Successfully applied ... migrations` 之前的错误 | 确认 `youmingdb` 为空库；Flyway 在空库自动 migrate，存量库需先 `DROP SCHEMA public CASCADE` 或调整 `baseline-on-migrate` |
| 启动报 `No value provided for placeholder: ${...}` | Flyway 未禁用 placeholder 替换；确认 `spring.flyway.placeholder-replacement: false`（gen_template 种子数据含 Velocity 变量） |
| 连接报 `authentication failed` | PostgreSQL 凭证不符，用 `PG_USER`/`PG_PASSWORD` 环境变量覆盖（见 4.2） |
| 连接报 `database "youmingdb" does not exist` | 未创建空库，先 `CREATE DATABASE youmingdb;`（见 3.1） |
| `npm run dev` 报 Node 版本不足 | 升级 Node 至 18+（推荐 20 LTS） |
| 前端登录验证码不显示 | 未将 `VITE_IS_MICRO` 改为 `false`，或后端 `/admin/code/image` 未就绪 |
| `mvn` 找不到 `pig-boot` 模块 | 未加 `-Pboot` profile；默认 profile 不包含该模块 |
| 端口 9999 被占用 | 关闭占用进程，或在 `application.yml` 改 `server.port` |
| Java 扩展识别不到项目 | 确认打开的是仓库根目录，Maven 扩展已安装并加载 `server/pom.xml` |
