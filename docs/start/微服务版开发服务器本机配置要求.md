# 微服务版开发服务器本机配置要求

> 适用对象：使用 pig 微服务架构（`pig-register` + `pig-gateway` + `pig-auth` + `pig-upms-biz` + `pig-visual` 等）进行本机开发调试的开发者。
> IDE：Visual Studio Code（不适用 IntelliJ IDEA）。
> 后端目录：`server/`，前端目录：`web/`。

## 一、架构说明

微服务版完整启动包含以下服务，**启动有先后顺序**（Nacos 必须最先就绪）：

| 模块 | 启动类 | 端口 | 作用 |
|------|--------|------|------|
| `pig-register` | `com.alibaba.nacos.bootstrap.PigNacosApplication` | 8848 / 18080 | 内嵌 Nacos 3.2.2（standalone），注册中心 + 配置中心，控制台 `http://127.0.0.1:18080/nacos` |
| `pig-gateway` | `com.pig4cloud.pig.gateway.PigGatewayApplication` | 9999 | Spring Cloud Gateway，统一入口、路由转发 |
| `pig-auth` | `com.pig4cloud.pig.auth.PigAuthApplication` | 3000 | 认证授权服务（OAuth2） |
| `pig-upms-biz` | `com.pig4cloud.pig.admin.PigAdminApplication` | 4000 | 用户权限管理（核心业务） |
| `pig-visual/pig-codegen` | `com.pig4cloud.pig.codegen.PigCodeGenApplication` | — | 代码生成器（可选） |
| `pig-visual/pig-monitor` | `com.pig4cloud.pig.monitor.PigMonitorApplication` | 5001 | Spring Boot Admin 服务监控（可选） |
| `pig-visual/pig-quartz` | `com.pig4cloud.pig.daemon.quartz.PigDaemonQuartzApplication` | — | 定时任务（可选） |

配置下发链路：

- 各微服务 `application.yml` 仅含端口与 Nacos 地址，实际数据源/Redis/路由等配置通过 `spring.config.import` 从 Nacos 拉取：
  - `application-dev.yml`（全局：Redis 指向 `pig-redis`、mybatis-plus、openfeign 等）
  - `pig-gateway-dev.yml` / `pig-auth-dev.yml` / `pig-upms-biz-dev.yml` / `pig-codegen-dev.yml` / `pig-quartz-dev.yml` / `pig-monitor-dev.yml`
- 这些配置的初始内容来自 `server/db/pig_config.sql`，导入到 `pig_config` 库后由 Nacos 读取。
- Maven `cloud` profile 定义 `nacos.username=nacos / nacos.password=nacos / profiles.active=dev`，编译时替换 `application.yml` 中的 `@nacos.username@` 等占位符。

## 二、本机配置要求

### 2.1 软件环境

| 软件 | 版本要求 | 说明 |
|------|---------|------|
| JDK | 17（必须） | `maven.compiler.source/target=17` |
| Maven | 3.8+ | 编译微服务模块，需激活 `cloud` profile（默认激活） |
| Node.js | 18.x+（推荐 20 LTS） | 前端 Vite 8 |
| MySQL | 8.x | 需创建 `pig` 与 `pig_config` 两个库；`lower_case_table_names=1` |
| Redis | 6.x / 7.x | 微服务版默认使用 db `0`（由 Nacos 中 `application-dev.yml` 决定，未指定则默认 0） |
| Git | 2.20+ | — |
| Docker（可选） | — | 用 `docker-compose.yml` 一键起 MySQL/Redis/register 等容器 |

### 2.2 VSCode 必装扩展

| 扩展 | 用途 |
|------|------|
| **Extension Pack for Java**（vscjava） | Java 调试 + Maven 集成 |
| **Spring Boot Extension Pack** | yml 智能补全、Bean 跳转 |
| **Vue - Official**（Volar） | Vue 3 支持 |
| **ESLint** / **Prettier** | 前端规范 |

> 多模块微服务调试建议：VSCode 的 Java 调试支持同时挂载多个 launch 配置，但**同一窗口只能启动一个主类**。微服务需多个进程并行，推荐用「一个 launch 调试主服务 + 其余服务用终端 `mvn spring-boot:run` 或编译后 `java -jar` 后台跑」的方式（见第六节）。

### 2.3 硬件建议

- CPU 8 核及以上（多个 JVM 并行）
- 内存 16 GB 及以上（每个微服务 ~512MB~1GB，Nacos ~1GB）
- 磁盘 15 GB 可用空间

## 三、中间件准备（MySQL / Redis）

### 3.1 初始化 MySQL（必须导入两个库）

```bash
# 业务库
mysql -uroot -p < server/db/pig.sql
# Nacos 配置库（微服务版必须，含所有微服务的 Nacos 配置）
mysql -uroot -p < server/db/pig_config.sql
```

- `pig`：业务数据（用户、角色、菜单等）。
- `pig_config`：Nacos 配置中心数据（`config_info` 表内含 `application-dev.yml` 及各 `pig-*-dev.yml`）。

> ⚠️ `pig_config.sql` 必须导入，否则微服务启动后从 Nacos 拉不到数据源配置，会报连接错误。

### 3.2 启动 Redis

```bash
redis-server --daemonize yes
# 或
docker run -d --name pig-redis -p 6379:6379 redis:7
```

### 3.3 修改 Nacos / 微服务中的主机名

默认配置中所有数据源与 Redis 指向容器主机名 `pig-mysql` / `pig-redis`，本机调试需改为 `127.0.0.1`。两种方式（任选其一）：

**方式 A：环境变量覆盖（推荐，不改代码）**

`pig-register` 与各 `pig-*-dev.yml` 已对数据源做了 `${MYSQL_HOST:pig-mysql}` 占位，启动时设环境变量即可覆盖：

```bash
export MYSQL_HOST=127.0.0.1
export MYSQL_PORT=3306
export MYSQL_DB=pig
export MYSQL_USER=root
export MYSQL_PWD=root     # 本机 MySQL 实际密码
```

> 注意 `pig-register` 连的是 `pig_config` 库，其 `db.url.0` 用 `${MYSQL_DB:pig_config}`，故 `MYSQL_DB` 需保持 `pig_config`——register 与业务库的 `MYSQL_DB` 默认值不同。建议 register 单独设 `MYSQL_DB=pig_config`，业务服务在 Nacos 中改（见方式 B）。

**方式 B：在 Nacos 控制台修改配置（直观）**

Nacos 启动后，登录 `http://127.0.0.1:18080/nacos`（账号 `nacos / nacos`），在「配置管理 → 配置列表」编辑：

- `application-dev.yml`：将 `spring.data.redis.host` 由 `pig-redis` 改为 `127.0.0.1`。
- `pig-upms-biz-dev.yml`、`pig-codegen-dev.yml`、`pig-quartz-dev.yml`：将 `${MYSQL_HOST:pig-mysql}` 改为 `127.0.0.1`，密码改本机实际值。

> 修改后发布即生效，无需重启 Nacos；已启动的微服务需重启或刷新配置。

## 四、后端编译

```bash
cd server
mvn clean install -Pcloud -DskipTests
```

- `cloud` profile 为默认激活，包含除 `pig-boot` 外的所有模块。
- 首次编译耗时较长，建议配置阿里云 Maven 镜像。
- 编译后各模块 `target/` 下生成可运行 jar（如 `pig-register/target/pig-register.jar`）。

## 五、VSCode 启动配置

在仓库根目录创建 `.vscode/launch.json`，为每个微服务配置一个 launch 项：

```json
{
  "version": "0.2.0",
  "configurations": [
    {
      "type": "java",
      "name": "1-Nacos (pig-register)",
      "request": "launch",
      "mainClass": "com.alibaba.nacos.bootstrap.PigNacosApplication",
      "projectName": "pig-register",
      "cwd": "${workspaceFolder}/server",
      "vmArgs": "-Xms512m -Xmx1024m",
      "env": {
        "MYSQL_HOST": "127.0.0.1",
        "MYSQL_PORT": "3306",
        "MYSQL_DB": "pig_config",
        "MYSQL_USER": "root",
        "MYSQL_PWD": "root"
      }
    },
    {
      "type": "java",
      "name": "2-Gateway (pig-gateway)",
      "request": "launch",
      "mainClass": "com.pig4cloud.pig.gateway.PigGatewayApplication",
      "projectName": "pig-gateway",
      "cwd": "${workspaceFolder}/server",
      "vmArgs": "-Xms256m -Xmx512m",
      "env": { "NACOS_HOST": "127.0.0.1", "NACOS_PORT": "8848" }
    },
    {
      "type": "java",
      "name": "3-Auth (pig-auth)",
      "request": "launch",
      "mainClass": "com.pig4cloud.pig.auth.PigAuthApplication",
      "projectName": "pig-auth",
      "cwd": "${workspaceFolder}/server",
      "vmArgs": "-Xms256m -Xmx512m",
      "env": { "NACOS_HOST": "127.0.0.1", "NACOS_PORT": "8848" }
    },
    {
      "type": "java",
      "name": "4-UPMS (pig-upms-biz)",
      "request": "launch",
      "mainClass": "com.pig4cloud.pig.admin.PigAdminApplication",
      "projectName": "pig-upms-biz",
      "cwd": "${workspaceFolder}/server",
      "vmArgs": "-Xms256m -Xmx512m",
      "env": {
        "NACOS_HOST": "127.0.0.1", "NACOS_PORT": "8848",
        "MYSQL_HOST": "127.0.0.1", "MYSQL_PWD": "root"
      }
    }
  ]
}
```

> `NACOS_HOST`/`NACOS_PORT` 覆盖各服务 `application.yml` 中的 `${NACOS_HOST:pig-register}`，使微服务连本机 Nacos 而非容器主机名。

## 六、启动顺序与步骤

### 6.1 启动顺序（严格）

1. **MySQL + Redis**（本机或容器）就绪，已导入 `pig.sql` + `pig_config.sql`。
2. **pig-register（Nacos）** —— 必须最先且完全就绪。
3. **pig-gateway** —— 依赖 Nacos 配置。
4. **pig-auth** / **pig-upms-biz** —— 依赖 Nacos 配置与 gateway。
5. **（可选）** pig-codegen / pig-monitor / pig-quartz。
6. **前端** `web/`。

### 6.2 VSCode 启动步骤

1. 打开仓库根目录 `youming/`。
2. 先设置环境变量（若用方式 A），或在 launch.json 的 `env` 中已配置（推荐）。
3. 在运行配置下拉选 `1-Nacos (pig-register)`，按 `F5` 启动。
4. 等待 Nacos 就绪：访问 `http://127.0.0.1:18080/nacos`（nacos/nacos）能登录即成功；或看控制台 `Nacos started successfully`。
5. 依次启动 `2-Gateway`、`3-Auth`、`4-UPMS`（每个按 `F5`；VSCode 默认一次启动一个，下个需在前一个控制台保持运行后启动）。
   - **多进程并行调试技巧**：VSCode Java 调试器支持同时运行多个配置——在运行面板可点击多个配置的运行按钮；或用 `compounds` 同时启动一组。但资源占用高，建议主力调试服务用 `F5` 调试，其余用终端后台运行：
     ```bash
     cd server
     nohup java -jar pig-auth/target/pig-auth.jar > /tmp/pig-auth.log 2>&1 &
     nohup java -jar pig-upms/pig-upms-biz/target/pig-upms-biz.jar > /tmp/pig-upms.log 2>&1 &
     ```
6. 全部就绪后，通过网关访问：`http://127.0.0.1:9999`，路由前缀 `/auth/**`→认证、`/admin/**`→UPMS、`/gen/**`→codegen、`/job/**`→quartz、`/monitor/**`→monitor。

> 断点调试：在被 `F5` 启动的服务（如 pig-upms-biz）的任意方法设断点，前端触发请求经 gateway 路由过来后命中即暂停。

## 七、前端配置与启动

### 7.1 确认微服务模式

`web/.env` 默认即为微服务模式，无需修改：

```
VITE_IS_MICRO=true
VITE_API_URL=/api
VITE_ADMIN_PROXY_PATH=http://127.0.0.1:9999
```

> `VITE_IS_MICRO=true` 时，验证码等请求走 `/auth/**`，经 Vite 代理转发到 gateway 9999。

### 7.2 启动

```bash
cd web
npm install
npm run dev
```

浏览器自动打开 `http://127.0.0.1:8888`，请求经 Vite 代理到 `http://127.0.0.1:9999`（gateway）。

## 八、启动顺序总结

1. MySQL（含 `pig` + `pig_config` 两库）、Redis 就绪。
2. `mvn clean install -Pcloud -DskipTests`。
3. VSCode `F5` 启动 `pig-register`，等 Nacos 就绪。
4. 依次 `F5` 启动 `pig-gateway` → `pig-auth` → `pig-upms-biz`。
5. （可选）codegen / monitor / quartz。
6. `web/` 下 `npm install && npm run dev`，打开 `http://127.0.0.1:8888`。

## 十、常见问题

| 现象 | 原因 / 处理 |
|------|------------|
| 微服务启动报 `Connection refused pig-register:8848` | Nacos 未启动或 `NACOS_HOST` 未改为 `127.0.0.1` |
| Nacos 启动报 `Unknown database 'pig_config'` | 未导入 `pig_config.sql` |
| 微服务拉不到数据源配置（报 MySQL 连接错误） | `pig_config.sql` 未导入，或 Nacos 中 `pig-*-dev.yml` 被删；登录 Nacos 控制台确认配置存在 |
| 微服务连 MySQL 报 `Unknown host pig-mysql` | 未用环境变量覆盖 `MYSQL_HOST`，或未在 Nacos 控制台改主机名 |
| gateway 9999 起来但请求 404 | 对应业务服务（如 pig-upms-biz）未启动，路由 `lb://` 找不到实例 |
| 前端验证码不显示 | `VITE_IS_MICRO` 应为 `true`；或 pig-auth 未就绪 |
| 内存不足/卡顿 | 多个 JVM 并行占用大，调小各 `vmArgs` 的 `-Xmx`，或用终端后台跑非调试服务 |
| VSCode 一次只能调试一个 Java 进程 | 用 `compounds` 组合启动，或主力服务 `F5`、其余终端 `java -jar` |
